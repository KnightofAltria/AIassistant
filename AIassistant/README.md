# 计算机课程学习助手（本地可运行版）

按 `设计文档.txt` 实现的第一个可运行版本：**不登录、不用本地模型，只接 DeepSeek API**，
所有数据存在本机 `app/data/` 下，随时可删。

## 三步跑起来

```powershell
cd AIassistant\app
python server.py --open
```

1. 浏览器打开 `http://127.0.0.1:8737`
2. 在首页填入 DeepSeek API Key（[在这里申请](https://platform.deepseek.com/api_keys)）
3. 进入主界面

**没有任何第三方依赖**，不需要 `pip install`，Python 3.10+ 即可（用标准库实现
HTTP 服务、SSE 流式、SQLite 存储、BM25 检索）。

没有 Key 也能先看界面：

```powershell
python server.py --mock --open    # 离线演示模式，模型输出为占位文本
```

## 先导入资料，回答才会带出处

```powershell
python crawl.py              # 预览内置的抓取清单
python crawl.py --crawl      # 联网抓取并导入（9 篇，约 70 个切片）
```

也可以点界面右上角「导入资料」粘贴文本或选本地文件（.txt/.md/.csv/.json）。

## 目录

```
app/
  server.py       HTTP 服务与全部接口（含 SSE 流式）
  store.py        SQLite 存储与文件落盘（资料、会话、总结、错题、题目）
  rag.py          切片 + 中文 BM25 检索 + 引用编号 + 引用校验
  deepseek.py     DeepSeek 客户端（流式/非流式），--mock 离线后端
  prompts.py      全部提示词（改行为只改这里）
  seed.py         4 科目 19 章节的内置大纲
  crawl.py        公开资料抓取与导入
  selftest.py     端到端自检（22 项）
  static/         前端（原生 JS，无构建）
  data/           运行时数据：csla.db、materials/、config.json
```

## 自检

```powershell
# 终端 1
python server.py --mock
# 终端 2
python selftest.py
```

覆盖：静态资源、科目树、资料导入与切片、检索命中、SSE 事件顺序、引用校验、
会话落库、总结生成、章节讲解、出题与判分、易错本、文件夹、删除链路、错误码。

## 数据与隐私

- API Key 明文存在 `app/data/config.json`，只发给 `api.deepseek.com`。
- 聊天内容只存在本机 SQLite；发往 DeepSeek 的只有当前一轮的对话与检索到的资料片段。
- 想彻底清空：停掉服务，删掉 `app/data/` 整个目录即可。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 填了 Key 提示 401 | Key 无效或已删；到 platform.deepseek.com 重新生成 |
| 提示 402 | DeepSeek 账户余额不足 |
| 端口被占用 | `python server.py --port 9000` |
| 公司/校园网连不上 DeepSeek | 设置环境变量 `HTTPS_PROXY` 后再启动 |
| 回答里出现"资料不足" | 说明检索没命中，先在「资料管理」导入对应章节的资料 |
| 想换回真实模型但不想重填 Key | 右上「API 设置」里改模型即可 |
