# 计算机课程学习助手（本地可运行版）

按 `设计文档.txt` 实现的第一个可运行版本：**不登录、不用本地模型，只接 DeepSeek API**，
所有数据存在本机 `app/data/` 下，随时可删。

## 怎么启动

**最简单的办法：双击**

```
AIassistant\启动.bat      （或 run.bat，同一个东西）
```

会弹出一个黑窗口，自动找 Python、启动服务、打开浏览器 `http://127.0.0.1:8737`。
首次进入先填 DeepSeek API Key（[在这里申请](https://platform.deepseek.com/api_keys)）。

**关掉就停**：启动脚本带 `--exit-on-close`，关掉最后一个浏览器页面约 25 秒后，
服务会自动停止，黑窗口自己退出。想立刻停：窗口里按 Ctrl+C，或直接关窗口。

命令行启动也可以：

```powershell
cd AIassistant\app
python server.py --open --exit-on-close     # 关页面即停服
python server.py --open                     # 不自动退出，适合长期挂着
```

相关参数：`--exit-on-close`（开关）、`--idle-visible 25`（页面可见时空闲上限秒数）、
`--idle-hidden 300`（页面切后台时的上限）。

**没有任何第三方依赖**，不需要 `pip install`，Python 3.10+ 即可（用标准库实现
HTTP 服务、SSE 流式、SQLite 存储、BM25 检索）。

没有 Key 也能先看界面：

```powershell
python server.py --mock --open    # 离线演示模式，模型输出为占位文本
```

## 资料是怎么组织的

```
资料管理
├── 🔒 核心资料 core       本机维护的计算机核心知识：课程地图、学习方法、基础概念速查
├── 📁 计算机组成原理       计组课件、笔记、习题
├── 📁 计算机网络
├── 📁 操作系统
└── 📁 数据结构
```

- **核心资料 core** 由本机维护，内容会被所有科目的提问检索到（这也是"core"的含义：公共底座），
  所以不建议随意改动；界面会显示黄色提示条，删除时也会二次确认。但允许修改，改了会影响全部科目的回答。
- 各科文件夹互相隔离：问「补码」不会去检索计算机网络资料（科目路由，见下文）。
- 点资料标题即可在浏览器新标签页打开源文件；源文件就在 `data/materials/` 下，路径可一键复制。
- 删除文件夹时可选「只删文件夹，资料移到根目录」或「连同资料一起删」，避免误删。

## 让 AI 直接改软件（tools / function calling）

资料管理和科目学习页各有一个指令框，说一句话模型就会调用工具真正改动数据：

| 你说的 | 模型会做的事 |
|---|---|
| 「看看哪些资料放错了」 | `list_folders` → `list_materials` → 指出问题 |
| 「按科目整理一下」 | `classify_materials` 直接归类 |
| 「把讲 TCP 的都放到计算机网络」 | 多次 `move_material` |
| 「这个链接帮我存下来」 | `import_url` 抓正文、切片、入库 |
| 「给操作系统加一章：进程通信」 | `add_chapter`（并补大纲） |
| 「把树那一章改名为树与二叉树」 | `update_chapter` |
| 「删掉自检临时章节」 | 先返回"待确认"，用户同意后再 `delete_chapter(confirm=true)` |

设计上的两条硬约束：

1. **删除必须二次确认**：工具第一次调用只返回"即将删除什么"，不会真删；模型把这个问句转给用户，
   用户同意后模型才能带 `confirm=true` 再来一次。
2. **内置科目/章节删不掉**：`delete_subject` / `delete_chapter` 遇到 `is_builtin` 直接拒绝并说明原因。

抓网页做了 SSRF 防护：只允许 http/https、解析域名后拒绝内网/回环/保留地址、限制 2 MB、超时 20 秒。

## 检索是怎么做的（以及为什么这么设计）

没有用向量库，因为 DeepSeek 不提供 embedding 接口，而引入本地嵌入模型又要多装几百 MB。
当前实现是纯词法检索，四层策略：

1. **分词**：中文单字 + 二元组（"栈""队列""依赖"都进索引），英文按词。
   单字必须收，否则"栈和队列有什么区别"匹配不到只有"栈"那一篇。
2. **虚词闸门**：由两个停用字组成的二元组（"不能""什么""怎么"）直接丢弃。
   不加这一步，长文档靠虚词堆分就能压过真正相关的短文档。
3. **标题加权**：命中人工命名的标题额外加分，标题的信噪比最高。
4. **科目路由**：先全库检索，按得分判断属于哪一科，再限定该科重检，避免跨科目串味。

**资料不足的判定**用两道闸门：绝对分过低，或"分数不高且查询词覆盖率 < 60%"。
阈值是离线校准的（相关问题覆盖度 0.62~1.00，无关问题 0.25~0.57），见 `rag.py` 里的常量。
判为资料不足时，系统会要求模型明确说"资料中没有找到足够依据"，并且**不展示任何引用编号**。


会话落库、总结生成、章节讲解、出题与判分、易错本、文件夹、删除链路、错误码。

## 数据与隐私

- API Key 明文存在 `app/data/config.json`，只发给 `api.deepseek.com`。
- 聊天内容只存在本机 SQLite；发往 DeepSeek 的只有当前一轮的对话与检索到的资料片段。
- 想彻底清空：停掉服务，删掉 `app/data/` 整个目录即可。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 填了 Key 提示 401 | Key 无效或已删；到 platform.deepseek.com 重新生成 |
| 提示 402 | DeepSeek 账户余额不足 |
| 端口被占用 | `python server.py --port 9000` |
| 公司/校园网连不上 DeepSeek | 设置环境变量 `HTTPS_PROXY` 后再启动 |
| 回答里出现"资料不足" | 说明检索没命中，先在「资料管理」导入对应章节的资料 |
| 想换回真实模型但不想重填 Key | 右上「API 设置」里改模型即可 |
