# UI 与功能合并版

日期：2026-10-31。功能基线：`功能完善的agent/AIassistant`；界面基线：原 `AIassistant` UI 优化版。

## 使用

先关闭旧版网页并等旧服务退出，再双击 `AIassistant/启动.bat`。两个版本默认使用相同端口 8737，不应同时运行。需要 Python 3.10 或以上。启动器隐藏控制台；登录成功进入粒子欢迎页，点击“开始学习”进入首页。首次使用还需完成模型 Key 配置。

这是干净的独立交付副本，未复制原版的账号数据库、API Key、登录会话和私人学习数据。原来的两个文件夹均未改动。已有账号能否登录取决于使用的认证服务；若使用本副本自动启动的全新本机认证服务，需要注册新账号。不要在旧版服务未退出时判断自己是否打开了新版本。

## 完善版相对 UI 版新增了什么

| 项目 | 本次核对的差异 |
| --- | --- |
| 资料阅读 | 从打开原始文件改为应用内阅读页，支持排版/原文切换、文本下载、资料深链接、刷新与前进后退 |
| Markdown | 增加表格、有序和嵌套列表、分隔线、链接、删除线等排版；转义 HTML、限制链接协议 |
| Word | 导入时保留原始 DOCX，提供原文件下载；阅读页解析标题、段落、编号、表格、图片及常用文字格式；删除资料同步删除原文件 |
| 档案与总结 | Markdown 排版展示，替代直接显示原文 |
| 回归检查 | 增补 Word 解析、原文件保留与下载等测试 |

登录注册、账号数据隔离、资料搜索/筛选/排序、批量移动/删除、拖入文件夹、头像处理、登录设备管理等代码在两个版本中已经存在，并非这次新增。其功能随完善版一起保留。

## 合并决策

- 后端以完善版为准，保留 UI 版个人简介字段及服务端校验，避免 UI 的保存功能失效。
- 保留蓝白配色、粒子欢迎页、卡片首页、SVG 图标、提示气泡、动画偏好、个人信息入口和头像拖放。
- 新阅读页使用同一套色彩、边框和按钮样式；完整保留完善版的阅读接口及文件处理。
- 保留隐藏启动器、登录清除旧深链接回欢迎页的修复，以及回答缓存失效修复。
- 样式使用完善版基础样式和 UI 版视觉覆盖，避免遗漏阅读样式或媒体查询边界。
