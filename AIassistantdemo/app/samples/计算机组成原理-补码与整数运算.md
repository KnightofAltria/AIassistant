# 补码与整数运算（示例资料）

## 为什么用补码

计算机用定长二进制表示整数，n 位只能表示 2^n 个不同的值。若把最高位当符号位，剩下
n-1 位表示大小，就有两个零（+0 与 -0），而且减法需要单独的硬件。

补码用一个统一的规则解决这两个问题：负数按「绝对值的各位取反再加一」表示。
等价地说，补码把 -x 表示为 2^n - x。

## 补码为什么能把减法变成加法

关键在于**模运算**。n 位加法器只保留低 n 位，最高位的进位被丢弃，这恰好等于对 2^n 取模。
在模 2^n 的意义下：

```
-b 的补码 = 2^n - b ≡ -b  (mod 2^n)
a - b ≡ a + (2^n - b)  (mod 2^n)
```

所以减法可以改写为「加一个数的补码」，用同一个加法器完成，减法器就省掉了。
这同时解释了为什么补码只有一个零：+0 是 0，-0 也是 0，两者补码相同。

## 8 位例子：7 - 5

```
 5 = 0000 0101   取反 = 1111 1010   加 1 = 1111 1011（即 251 = 256 - 5）
 7 = 0000 0111
 0000 0111
+1111 1011
---------
1 0000 0010   ← 第 9 位进位丢弃，低 8 位 = 2
```

结果是 2，等于 7 - 5。

## 表示范围与溢出

n 位补码的范围是 -2^(n-1) 到 2^(n-1)-1，负数比正数多一个（8 位是 -128~127）。
原因是 1000 0000 这个编码没有对应的正数，被规定为 -128。

溢出的判断：**两个同号数相加，结果符号变了就是溢出**。例如 8 位的 127 + 1：
0111 1111 + 0000 0001 = 1000 0000，看起来是 -128，实际真值是 128，超出范围，结果无效。
工程上还可以看「最高位进位」与「次高位进位」是否相同，不同即溢出。
