# 主界面与功能快照合并版

新版本入口：`AIassistant/启动.bat`。先关闭旧版服务，两版默认都使用 8737 端口。

## 对比与合并依据

界面来源：main 的 `AIassistant-merged/AIassistant`（fc312b7）。功能来源：`分支快照/AIassistant-feat-auth/AIassistant`。以 5bbac33 的资料阅读版本为共同基线，逐文件三方合并。

| 范围 | main merged | 分支快照 | 新版本 |
| --- | --- | --- | --- |
| 首页与视觉 | 卡片首页、粒子欢迎页、SVG 图标、动画偏好 | 较早界面 | 保留 main |
| 个人信息 | 简介、头像拖放、个人信息入口 | 基本账号管理 | 保留 main 并补充管理功能 |
| 资料阅读 | Markdown、Word 阅读与下载 | 新增 PDF | 合并保留 |
| 源文件 | Word 原文件下载 | 多种源文件保存、浏览器或本机打开 | 采用快照功能 |
| 数据清除 | 原有记录管理 | 按类别清除本人记录 | 加入确认弹窗及接口 |
| 角色权限 | 原有认证与账号隔离 | 管理员管理、核心资料只读 | 加入前后端权限控制 |
| 资料顺序 | 按字段排序、拖动移到文件夹 | 文件夹内手动排序 | 保留两种拖动行为 |

冲突处理：资料核心目录的提示保留 main SVG 图标，同时使用快照的管理员和只读提示；文件夹编辑按钮由权限字段控制。隐藏启动器、欢迎页跳转、简介字段以及原有 Word 阅读功能均保留。

未复制 data、账号数据库、登录会话、API Key 和缓存。新目录不改动两个来源。新建的本机认证服务需要重新注册账号；管理员按认证服务器 grant-admin 命令配置。
