## 0 文档介绍

### 0.1 文档目的

描述 CSLA 的界面结构、页面元素、交互规则与视觉风格，作为实现与验收依据。本文回答"用户看到什么、怎么操作、出错时得到什么反馈"。

### 0.2 文档范围

覆盖设计规范、页面关系、各页面元素与交互、美学与资源。不涉及接口协议（见 I-1）与业务规则（见 G-2）。

### 0.3 读者对象

界面实现者、测试人员、评审人。

### 0.5 术语与缩写解释

| 术语 | 解释 |
|---|---|
| 视图（view） | 单页应用中的一个页面容器，由 `switchView` 切换 |
| 返回条 | 每个功能页左上角注入的「← 返回」「⌂ 主界面」按钮组 |
| 卡片 | 首页的五个功能入口，顺序与侧边栏一致 |
| 粒子层 | Canvas 绘制的背景动画，含漂浮节点、稀疏连线、点阵与光带 |
| 波纹 | 鼠标移动时在欢迎界面产生的扩散圆环 |
| SSE 增量 | 流式回答的逐字片段 |

## 1 应当遵循的界面设计规范

| 编号 | 规范 | 说明 |
|---|---|---|
| U1 | 简洁明快优先 | 背景动效不得干扰文字可读性；文字对比度 ≥ 4.5:1 |
| U2 | 每个功能页都能回到首页 | 统一由返回条提供，不用浏览器后退 |
| U3 | 主界面不显示侧边栏 | 首页全宽展示五个入口卡；进入功能页才出现侧边栏 |
| U4 | 危险操作须二次确认 | 删除资料、删除文件夹、删除科目、删除内置章节均弹确认框 |
| U5 | 错误就地提示 | 表单错误显示在字段下方；接口错误用页面内提示条，不用原生 `alert` |
| U6 | 中文优先 | 界面文案、提示语、错误信息全为中文 |
| U7 | 键盘可达 | Tab 遍历可交互元素、Enter 发送、Esc 关闭弹窗 |
| U8 | 响应式下限 | 1366×768 起不出现横向滚动；侧边栏在窄屏收窄为图标 |

## 2 界面的关系图和工作流程图

### 2.1 页面关系

```
                  ┌──────────────┐
                  │  欢迎界面     │  粒子 + 鼠标波纹 + 「开始学习」
                  └──────┬───────┘
                         │ 点击「开始学习」（淡出）
                  ┌──────▼───────┐
                  │   首页        │  「今天学点什么？」+ 五张入口卡（隐藏侧边栏）
                  └──┬──┬──┬──┬──┘
        ┌────────────┘  │  │  └────────────┐
   ┌────▼─────┐  ┌──────▼──┐ ┌▼─────────┐ ┌▼──────────┐
   │个人信息   │  │AI 聊天   │ │近期总结   │ │科目学习    │
   └────┬─────┘  └────┬────┘ └────┬──────┘ └────┬──────┘
        │             │           │             │      ┌──────────┐
        └─────────────┴─────┬─────┴─────────────┴──────┤资料管理   │
                            │                          └──────────┘
                     任意功能页 → 「← 返回」/「⌂ 主界面」→ 回首页
```

### 2.2 主流程：导入资料 → 提问 → 看引用

```
首页 → 资料管理 → 导入文件/粘贴网址 → 选择文件夹 → 保存
     → AI 聊天 → 输入问题 → 流式回答 → 点击 [c1] → 查看原文片段
```

### 2.3 主流程：按章节学习

```
首页 → 科目学习 → 选择科目 → 选择章节 → 大纲/讲解 → 做题 → 判分
     → 答错：进入易错本 → 近期总结中可看易错提示本
```

## 3 主界面

### 3.1 欢迎界面

```
┌──────────────────────────────────────────────────────────┐
│  （全屏 Canvas：漂浮粒子 + 稀疏连线 + 极淡点阵与光带）      │
│  鼠标移动处浮现扩散圆环（波纹）                            │
│                                                          │
│                 计算机课程学习助手                        │
│              把资料变成会讲出处的答疑                      │
│                                                          │
│                   ┌────────────┐                         │
│                   │  开始学习   │  （进入 1.6 秒后浮现）   │
│                   └────────────┘                         │
└──────────────────────────────────────────────────────────┘
```

| 元素 | 行为 |
|---|---|
| 粒子层 | 流场驱动成束游弋；每节点最多 1 条连线（阈值 120px），避免过密 |
| 鼠标波纹 | 移动超过 16px 生成一圈，最长存活约 1.5 秒；点击时一次放 3 圈 |
| 「开始学习」 | 出现后点击：欢迎页 0.42 秒淡出，**直接露出首页**（不经过聊天页） |
| 未配置密钥 | 收起欢迎页，显示配置页 |

### 3.2 首页

```
┌──────────────────────────────────────────────────────────┐
│        （自带更克制的粒子背景，无侧边栏）                   │
│                                                          │
│                   今天学点什么？                          │
│                                                          │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐  │
│  │ 个人信息│ │ AI 聊天 │ │近期总结 │ │科目学习 │ │资料管理│  │
│  │  简介   │ │  简介   │ │  简介   │ │  简介   │ │  简介  │  │
│  └────────┘ └────────┘ └────────┘ └────────┘ └────────┘  │
└──────────────────────────────────────────────────────────┘
```

- 五张卡片顺序与侧边栏一致：个人信息 → AI 聊天 → 近期总结 → 科目学习 → 资料管理。
- 卡片为整块可点击区域，悬停时轻微上浮与描边高亮。
- 首页**不出现返回按钮**，也不显示侧边栏。

## 4 子界面 A：AI 聊天与近期总结

### 4.1 AI 聊天

```
┌─────────────┬────────────────────────────────────────────┐
│ ← 返回 ⌂主界面│  会话标题                        [查看总结] │
│             ├────────────────────────────────────────────┤
│ 个人信息     │  用户：TCP 为什么需要三次握手？             │
│ AI 聊天      │  AI：三次握手是为了…〔c1〕〔c2〕             │
│ 近期总结     │      ┌─────────────────────────┐           │
│ 科目学习     │      │ 引用 c1：计算机网络·TCP  │（点击展开）│
│ 资料管理     │      └─────────────────────────┘           │
│             ├────────────────────────────────────────────┤
│             │  [ 输入问题…                        ] [发送]│
└─────────────┴────────────────────────────────────────────┘
```

| 元素 | 说明 |
|---|---|
| 「查看总结」 | 位于聊天框上方，点击跳到「近期总结」中本会话的总结 |
| 引用胶囊 | 回答中 `[cN]` 渲染为可点击标签；点击展开该片段原文 |
| 流式输出 | 逐字追加；生成中「发送」变「停止」 |
| 失败提示 | 无证据时显示「资料里没有相关内容」；接口错误显示红色提示条并提供重试 |
| 空状态 | 无会话时显示引导文案与三个示例问题 |

### 4.2 近期总结

```
┌────────────────────────────────────────────────────────────┐
│ ← 返回 ⌂主界面    近期总结        [全部▾][对话][章节][易错本]│
├────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────────┐   │
│ │ TCP 三次握手 · 对话总结       2026-10-24   [放大查看] │   │
│ │ 要点预览：三次握手确认双方收发…                        │   │
│ └──────────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────────┘
```

| 元素 | 说明 |
|---|---|
| 类型筛选 | 全部 / 对话总结 / 章节小结 / 易错提示本 |
| 卡片 | 标题、类型标签、时间、首行预览；点击标题或「放大查看」打开弹窗 |
| 放大弹窗 | 宽 860px，内容按排版渲染（标题层级、列表、引用块），**不显示 Markdown 原文**；Esc 或点击遮罩关闭 |
| 删除 | 卡片右下「删除」，二次确认后移除 |

## 5 子界面 B：科目学习、资料管理、个人信息

### 5.1 科目学习

```
┌───────────────┬──────────────────────────────────────────┐
│ ← 返回 ⌂主界面 │ 计算机网络            [+ 添加章节]        │
│               │ ┌──────────────┐                          │
│ 计算机组成原理 │ │ 1 TCP 三次握手│ 内置                     │
│ 计算机网络 ◀  │ │ 2 HTTP 报文   │ 内置                     │
│ 操作系统       │ │ 3 自定义章节  │ 自定义      [编辑][删除] │
│ 数据结构       │ └──────────────┘                          │
│ [+ 添加科目]   │ 章节详情：大纲 / 讲解 / 做题 / 小结 / 视频 │
└───────────────┴──────────────────────────────────────────┘
```

| 元素 | 说明 |
|---|---|
| 科目列表 | 内置四科带「内置」标识，不可删除；自定义科目可删 |
| 添加科目 | 弹窗说明"需要时间从网上采集资料"，确认后创建并生成章节 |
| 章节详情 | 五个操作按钮：生成讲解、出题、查看小结、推荐视频、AI 指令框 |
| 做题 | 单选，选完立即判分并显示解析；答错写入易错本 |

### 5.2 资料管理

```
┌───────────────┬──────────────────────────────────────────┐
│ ← 返回 ⌂主界面 │ 资料管理        [导入文件][粘贴网址][新建文件夹]│
│               │ ┌─────────────┐ ┌──────────────────────┐   │
│ 核心资料 core │ │ 核心资料 3  │ │ 计算机组成原理 5 份   │   │
│ 计组 5        │ │ 计组 5      │ │ · 补码与整数运算      │   │
│ 计网 7        │ │ 计网 7      │ │ · 存储结构：Cache     │   │
│ 操作系统 6    │ │ …           │ │ 点击标题 → 查看原文    │   │
│ 数据结构 12   │ └─────────────┘ └──────────────────────┘   │
│               │ AI 指令框：[ 把这几份资料按科目归类…   ] [执行]│
└───────────────┴──────────────────────────────────────────┘
```

| 元素 | 说明 |
|---|---|
| 文件夹 | 核心资料带标记，不可删除；其余可重命名、删除 |
| 删除文件夹 | 弹窗给两种模式：「资料移到根目录」/「连资料一起删除」，后者红色警示 |
| 打开资料 | 点击标题查看正文；提供下载与"在系统中打开源文件" |
| AI 指令框 | 输入自然语言执行整理；执行过程逐步显示调用了哪个工具 |

## 6 美学设计

| 维度 | 设定 |
|---|---|
| 主色 | 深蓝灰 `#1F3A5F`（标题）＋ 品牌蓝 `#5688E1`（强调） |
| 背景 | 浅灰白 `#F5F7FB` 渐变；粒子层为低透明度蓝白 |
| 字体 | 标题「微软雅黑」，正文「宋体」，等宽「Consolas」 |
| 字号 | 正文 14–14.5px；页面标题 18–20px；欢迎页主标题 34px |
| 圆角与阴影 | 卡片 12–14px 圆角，投影 `0 8px 24px rgba(31,58,95,.08)` |
| 动效 | 视图切换 0.2s 淡入；按钮悬停 0.15s；粒子常驻但透明度 ≤ 0.12 |
| 留白 | 页面左右内边距 32px；卡片间距 16–20px |
| 禁忌 | 不使用霓虹色、不做闪烁动画、文字不压在粒子上 |

## 7 界面资源设计

### 7.1 图标资源

| 图标 | 用途 | 来源 |
|---|---|---|
| ⌂ / ← | 返回条 | Unicode 字符，不用图片 |
| 🏠 个人信息 / 💬 AI 聊天 / 📊 近期总结 / 📚 科目学习 / 📁 资料管理 | 侧边栏与首页卡片 | Unicode emoji |
| 无自有位图图标 | — | 首版不使用图标字体与 SVG 图标库 |

### 7.2 图像资源

| 资源 | 形式 | 说明 |
|---|---|---|
| 背景粒子 | Canvas 实时绘制 | 无图片文件，随窗口自适应 |
| 波纹 | Canvas 实时绘制 | 环形描边，随鼠标产生 |
| 头像 | 首字文本 | 取用户名字首字渲染为圆形色块 |
| 空状态插图 | 无 | 用文字引导，不引入图片 |

### 7.3 界面组件

| 组件 | 出现位置 | 关键规格 |
|---|---|---|
| 按钮 | 全局 | 三档：主色实心（主操作）、描边（次操作）、红色（危险） |
| 输入框 | 配置页、聊天、指令框、表单 | 聚焦时描边变主色；错误时红色边框 + 下方提示 |
| 卡片 | 首页、总结、资料 | 悬停上浮 2px，阴影加深 |
| 弹窗 | 导入、设置、删除确认、科目编辑、总结放大 | 遮罩 40% 黑；Esc 关闭；点击遮罩关闭 |
| 提示条（toast） | 全局 | 顶部居中，2.5 秒自动消失；错误为红色 |
| 引用胶囊 | 聊天回答 | 小号圆角标签，点击展开原文 |
| 侧边栏 | 功能页 | 宽 220px，当前项高亮；首页隐藏 |
