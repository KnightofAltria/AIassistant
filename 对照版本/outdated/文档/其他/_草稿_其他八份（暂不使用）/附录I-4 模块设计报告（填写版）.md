## 1 模块命名规则

| 类别 | 规则 | 示例 |
|---|---|---|
| 后端文件 | 小写单词，无需下划线 | `server.py`、`rag.py`、`store.py` |
| 前端文件 | 小写单词 + `.js` | `app.js`、`landing.js` |
| 测试与工具脚本 | 动词或用途前缀 | `check.py`、`selftest.py`、`reindex.py`、`crawl.py` |
| 类名 | 大驼峰 | `Retriever`、`DeepSeekClient`、`Hit` |
| 函数名 | 小写下划线，动词开头 | `chunk_text`、`build_evidence`、`validate_citations` |
| 内部函数 | 前导单下划线 | `_decode`、`_fetch_curl`、`_mock_stream` |
| 常量 | 全大写 | `TITLE_BOOST`、`INSUFFICIENCY_FLOOR`、`STOP_CHARS` |
| 前端全局函数 | 小驼峰，挂在 window 上供跨文件复用 | `switchView`、`createField`、`goHome` |

## 3 后端子系统的模块设计

### 3.1 模块 M-B1：`server.py`

| 项 | 内容 |
|---|---|
| 职责 | 提供全部 HTTP 接口；把领域层的返回值编码为 JSON 或 SSE；管理静态资源与生命周期 |
| 对外接口 | `main()`（命令行入口）、路由常量、`Handler` 类 |
| 主要接口路径 | 状态 `/api/state`；配置 `/api/config`；问答 `/api/chat/stream`；指令 `/api/agent/stream`；资料 `/api/materials`、`/api/materials/{id}`、`/api/materials/{id}/raw`；文件夹 `/api/folders`；科目 `/api/subjects`、`/api/chapters`、`/api/chapters/{id}/tutor`、`/api/chapters/{id}/videos`；题库 `/api/questions`、`/api/attempts`、`/api/mistakes`、`/api/mistakes/tips`；总结 `/api/summaries`、`/api/summaries/generate`；档案 `/api/profile`、`/api/profile/meta`、`/api/profile/generate`；检索 `/api/rag/search`；会话 `/api/conversations`；生命周期 `/api/heartbeat`、`/api/client-closed` |
| 关键实现 | `do_GET/do_POST/do_PATCH/do_DELETE` 四个入口共用分发表；SSE 事件 `delta` / `citations` / `completed`；`ThreadingHTTPServer` 每连接一线程 |
| 异常处理 | 参数缺失 → 400；资源不存在 → 404；内置项保护 → 409；端口占用 → 打印中文提示并退出码 2；未捕获异常 → 500 并返回 `{"error": ...}` |
| 依赖 | store、rag、tools、crawl、deepseek、prompts、seed |

### 3.2 模块 M-B2：`store.py`

| 项 | 内容 |
|---|---|
| 职责 | 唯一的数据库与文件访问层 |
| 对外接口 | `Store()`；`ensure_user()`、`get_meta()`、`set_meta()`、`update_profile()`、`meta_summary()`；`list_folders()`、`create_folder()`、`delete_folder(id, mode)`；`list_materials()`、`add_material()`、`get_material_text()`、`delete_material()`、`assign_orphan_materials()`；`all_chunks()`、`replace_chunks()`；`subjects()`、`add_subject()`、`delete_subject()`、`chapters`、`add_chapter()`、`update_chapter()`、`delete_chapter()`；`questions()`、`add_questions()`、`delete_question()`；`record_attempt()`、`list_mistakes()`；`list_conversations()`、`messages()`、`append_message()`、`delete_conversation()`；`list_summaries()`、`add_summary()`、`delete_summary()`；`list_profiles()`；`stats()` |
| 关键实现 | 建表 + 按列存在性 `ALTER TABLE` 迁移；`PRAGMA foreign_keys=ON`；全部参数化查询；单事务批量写入切片 |
| 异常处理 | 记录不存在时返回空/抛 `KeyError`；写失败回滚并不留半成品资料 |
| 依赖 | 无（仅标准库 `sqlite3`、`uuid`、`os`） |

### 3.3 模块 M-B3：`rag.py`

| 项 | 内容 |
|---|---|
| 职责 | 检索与证据处理 |
| 对外接口 | `tokenize(text)`；`chunk_text(text)`；`class Retriever(chunks)` + `search(query, k, subject)`；`build_evidence(hits)`；`validate_citations(answer, citations, insufficient)`；`insufficient_evidence(hits)`；`route_subject(query, subjects)`；`strip_meta(text)` |
| 关键实现 | 中文单字 + 二元分词并过滤停用字；BM25（k1=1.5、b=0.75）；标题加权 3.0；证据预算 3,600 字符；覆盖度与分数双阈值判"资料不足" |
| 异常处理 | 空库返回空命中；引用编号越界一律剔除并在返回里标记 |
| 依赖 | 无 |

### 3.4 模块 M-B4：`tools.py`

| 项 | 内容 |
|---|---|
| 职责 | 模型可调用能力的注册与执行 |
| 对外接口 | `TOOLS`（schema 列表）、`tools_for_scope(scope)`、`run_tool(scope, name, args, ctx)`；注册装饰器 `_reg` |
| 工具清单 | 资料域：`list_folders`、`list_materials`、`move_material`、`classify_materials`、`create_folder`、`delete_material`、`import_url`、`search_materials`；学习域：`list_subjects`、`add_subject`、`delete_subject`、`add_chapter`、`update_chapter`、`delete_chapter`、`generate_questions` |
| 关键实现 | 每个工具声明参数 schema 与所属域；删除类强制 `confirm=true`；`import_url` 做 SSRF 校验（仅 http/https、拒绝回环与私有网段、2 MB 上限、20 秒超时） |
| 异常处理 | 参数不合法 → 返回 `{"error": "..."}` 让模型自行纠正；未确认的删除 → 返回拒绝说明 |
| 依赖 | store、crawl、rag |

### 3.5 模块 M-B5：`crawl.py`

| 项 | 内容 |
|---|---|
| 职责 | 按来源清单抓取网页并抽正文 |
| 对外接口 | `SOURCES`（22 条）；`fetch(url)`；`html_to_text(raw)`；`trim(text, limit)`；命令行 `--crawl` / `--force` |
| 关键实现 | 标签栈丢弃 nav/sidebar/toc/footer；优先 `article`/`main`；MathJax 取 `data-latex`；TeX 符号映射；编码依次尝试 utf-8/gb18030/gbk/big5；TLS 失败改用系统 `curl`；`--force` 先删旧再导入 |
| 异常处理 | 非 http/https 直接拒绝；HTTP 错误码抛 `RuntimeError` 并在命令行打印 `[失败]`；正文过短（< 400 字）判为页面结构变化并跳过 |
| 依赖 | 无（`urllib` + `subprocess`） |

### 3.6 模块 M-B6：`deepseek.py`

| 项 | 内容 |
|---|---|
| 职责 | 模型访问 |
| 对外接口 | `DeepSeekClient(api_key, model)`；`validate()`、`stream_chat(messages, ...)`、`complete(messages, ...)`、`chat_with_tools(messages, tools, ...)` |
| 关键实现 | `urllib` 直连 + SSE 行解析；`chat_with_tools` 实现"请求工具→执行→回填"循环；`mock` 模式生成本地占位流供无网演示 |
| 异常处理 | 401/403 → 提示 Key 无效；超时 → 提示网络；流中断 → 保留已收内容并标记未完成 |
| 依赖 | 无 |

### 3.7 模块 M-B7：`prompts.py`

| 项 | 内容 |
|---|---|
| 职责 | 集中管理全部提示词，便于评审与调优 |
| 对外接口 | 常量 `CHAT_SYSTEM`、`FOLLOWUP`、`SUBJECT_TUTOR_SYSTEM`、`QUESTION_GEN`、`SUMMARY_SYSTEM`、`PROFILE_SYSTEM`、`MISTAKE_SYSTEM`、`AGENT_MATERIALS_SYSTEM`、`AGENT_STUDY_SYSTEM` |
| 关键约定 | 引用编号必须逐个书写、禁止写区间；无证据时必须明说"资料里没有"；学习者信息只用于调整深浅，不得复述 |
| 依赖 | 无 |

### 3.8 模块 M-B8：`seed.py`

| 项 | 内容 |
|---|---|
| 职责 | 首次启动的数据准备 |
| 对外接口 | `SUBJECTS`（4 科 19 章）、`FOLDERS`（core + 四学科）、`ensure_folders()`、`seed_samples()`、`import_shared_samples()`、`reorganize()` |
| 关键实现 | 幂等：已存在则跳过；内置科目/章节打 `is_builtin=1`；示例资料写入后立即切片 |
| 异常处理 | 目录缺失时自动创建；重复启动不产生重复数据 |
| 依赖 | store、rag |

### 3.9 模块 M-B9：`reindex.py`

| 项 | 内容 |
|---|---|
| 职责 | 重建全部切片索引 |
| 对外接口 | 命令行入口，无参数 |
| 关键实现 | 遍历资料 → 取正文 → `chunk_text` → `replace_chunks`，同时打印进度 |
| 异常处理 | 单份资料失败不影响其余，最后汇总成功/失败数 |

## 4 前端子系统与工具链的模块设计

### 4.1 模块 M-F1：`app.js`

| 项 | 内容 |
|---|---|
| 职责 | 主视图逻辑：视图切换、接口封装、聊天流式渲染、科目/资料/总结/配置等页面交互 |
| 对外接口 | 全局函数 `api()`、`md()`、`esc()`、`toast()`、`switchView()`、`loadSummaries()`、`openSummary()`；页面初始化 |
| 关键实现 | `switchView(view)` 统一控制视图显隐与侧边栏；SSE 用 `fetch` + `ReadableStream` 解析；引用胶囊点击展开原文 |
| 异常处理 | 接口错误统一 `toast(..., true)`；流中断保留已显示内容并给重试按钮 |

### 4.2 模块 M-F2：`landing.js`

| 项 | 内容 |
|---|---|
| 职责 | 欢迎页与首页背景、导航栈、返回条注入、个人信息页 |
| 对外接口 | `createField(canvas, opts)`、`startHomeField()`、`go(view)`、`goHome()`、`goBack()`、`injectBackBars()`、`loadProfilePage()`、`loadMeta()`、`saveMeta()`、`loadChapterVideos()` |
| 关键实现 | 粒子流场（每节点最多 1 条连线）；鼠标波纹；导航栈 `push/pop`；`view-home` 不注入返回条、不显示侧边栏 |
| 异常处理 | Canvas 不可用时静默降级为纯色背景；个人信息加载失败不阻塞页面 |

### 4.3 模块 M-F3：`agent.js`

| 项 | 内容 |
|---|---|
| 职责 | 两个自然语言指令框（资料域、学习域） |
| 对外接口 | 指令提交与步骤渲染；科目创建弹窗联动 |
| 关键实现 | 消费 `/api/agent/stream`，逐步显示"调用了哪个工具、结果如何"；删除类操作要求用户确认 |
| 异常处理 | 工具报错原样展示，不吞异常 |

### 4.4 模块 M-F4：`keepalive.js`

| 项 | 内容 |
|---|---|
| 职责 | 维持自动停服所需的存活信号 |
| 对外接口 | 每 5 秒 `POST /api/heartbeat {visible}`；`pagehide`/`beforeunload` 时 `sendBeacon('/api/client-closed')` |
| 关键实现 | 刷新有 6 秒宽限，避免误停 |
| 异常处理 | 请求失败静默重试，不弹提示 |

### 4.5 模块 M-T1：`check.py`

| 项 | 内容 |
|---|---|
| 职责 | 零成本自检（20 项），日常改完即可跑 |
| 覆盖 | Python/JS 语法、前端重复声明、HTML 配平、静态资源、只读接口、页面关键元素、数据体检 |
| 约束 | **不调模型、不写库**，5 秒内完成 |

### 4.6 模块 M-T2：`selftest.py`

| 项 | 内容 |
|---|---|
| 职责 | 全链路自检（44 项），交付前跑一次 |
| 覆盖 | 状态、静态资源、科目树、心跳、工具化接口、科目章节增删改、内置保护、视频接口、资料导入与检索、聊天流、会话落库、总结生成、出题与判分、章节讲解、易错本、文件夹体系、资料详情、删除链路、错误处理 |
| 约束 | 会调用约 7 次模型并写测试数据，**结束自动清理**（会话/总结/错题/占位题/测试文件夹），不得污染用户库 |
