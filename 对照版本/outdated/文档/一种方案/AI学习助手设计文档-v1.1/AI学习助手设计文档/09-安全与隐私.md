# 安全隐私与数据生命周期设计

## 信任边界

浏览器输入、上传文件、外部网页、模型输出和可分发课程包均视为不可信。后端会话决定身份；数据库权限决定可见数据；模型只能生成建议。应用部署者负责来源授权和运行模式配置，不能用“本地模型”概括所有处理链路的隐私属性。

## 风险与控制

| 风险 | 实施控制 | 必须验证 |
|---|---|---|
| 用户或课程串数据 | 所有权校验、课程成员过滤、RLS、私有切片过滤 | 两用户两课程，伪造各类ID返回404或拒绝 |
| 提示注入与知识投毒 | 来源隔离、人工审核、资料作为数据、输出校验、模型无写权限 | 恶意文档不能发布或调用工具 |
| SSRF | 公网域名白名单、重定向与DNS复检、出站网络限制 | 私网、元数据地址、DNS重绑定拦截 |
| 上传攻击 | 大小/页数/类型/解压比限制、无宏执行、低权限解析 | 伪扩展名、压缩炸弹、路径穿越不落库 |
| XSS与危险引用 | Markdown净化、禁原始HTML、URL协议检查、CSP | 模型输出脚本与javascript链接不能执行 |
| 密钥泄露 | 环境注入或secret引用、日志脱敏、分发前扫描 | 前端包、导出包、错误响应不含密钥 |
| 未授权费用消耗 | 用户配额、并发限制、预算预留、取消与超时 | 达上限停用生成，重复请求不重复计费 |
| 非预期模型外呼 | strict_local策略涵盖嵌入/重排/诊断/OCR，网络层阻断 | 禁网下完整业务和出站日志检查 |
| 会话劫持与CSRF | TLS、HttpOnly Cookie、CSRF令牌、Origin校验、会话撤销 | 跨站写失败，退出后旧会话失效 |
| 分发包供应链 | 锁依赖、镜像摘要、校验和、无pickle导入 | 课程包篡改、zip-slip、未知格式拒绝 |

RAG和微调不能完全防止提示注入，因此安全控制必须限制外部内容能影响的权限和动作。[OWASP风险说明](https://genai.owasp.org/llmrisk/llm01-prompt-injection/)

## 参考仓库需要优先处理的事项

静态审阅src/file_scanner.py发现疑似硬编码API凭据默认值。本次不复制其值，不测试是否有效。若沿用该代码，应先由所有者核实并轮换相关凭据，删除代码默认值，检查历史与分发包；这项列为公开分发前阻断项。src/index_manager.py使用pickle持久化，不能加载用户或网络提供的pickle；新课程包采用JSON与受限文件清单。

示例web_app.py的本地模型失败路径存在转云逻辑，新项目strict_local必须禁止此行为。模型加载中的trust_remote_code应默认关闭，确需启用时先审查模型实现、固定版本并在隔离环境加载。

这些是读到的代码事实及工程建议，不代表已完成全面安全审计或确认凭据有效性。

## 权限矩阵

| 操作 | 学生 | 课程维护者 | 实例管理员 |
|---|---|---|---|
| 自己问答、练习、诊断 | 是 | 以学生身份使用 | 以学生身份使用 |
| 他人私人记录 | 否 | 默认否 | 默认否，受控支持流程另计 |
| 课程公共资料读取 | 已加入课程 | 授权课程 | 需相应成员或授权 |
| 上传私人资料 | 是 | 是 | 是 |
| 课程资料审核发布 | 否 | 授权课程 | 具课程管理授权时 |
| 系统模型与密钥配置 | 否 | 只选已批准路由 | 是，密钥不可回显 |
| 个人导出和删除 | 本人 | 本人 | 受控代办需留审计 |

## 数据最小化

默认测试账号不需要真实姓名、学校、年龄和联系方式。首次使用解释记录哪些信息、诊断用途、云端处理范围和删除方法。学习分析默认只使用当前课程作答，不跨课程聚合身份画像。拒绝可选行为统计不影响问答与练习。

真实未成年人、学校真实成绩和公开运营会改变适用要求，实施前需由项目负责人确认相关政策、同意流程和部署地区；本设计不作法律合规背书。学生数据不默认参与训练，研究或训练需要另行授权和去标识处理。

## 保留与删除

正文、学习证据和诊断默认180天，日志30天、非正文审计90天、备份30天。收到删除请求后立即隐藏并阻止新处理，7天内清理在线数据库、向量、资料、缓存、导出和派生画像；保留最小删除任务状态供确认。备份到期清除，恢复前重放删除清单。导出打包有效期24小时，下载签名10分钟。

删除流程需要二次认证，明确选择当前课程记录或全部个人数据。删除个人资料不删除他人拥有的公共课程资料；若包含用户投稿，分别按其版权和授权关系处理。禁止用删除日志重新写入已删除的完整内容。

## 成本与资源防护

初始用户每天50次生成、每会话5次/分钟、全实例5并发生成；参数可按作业预算调整。调用前预留输入加最大输出预算，完成后按真实usage结算；失败释放未消耗预留，缺少供应商usage时标为估算并对账。达到硬预算后拒绝新云任务，已开始任务遵守输出上限。价格按实际供应商当期配置录入，文档不固定未经核实的单价。
