# AIassistant · 计算机课程学习助手

北京理工大学大四卓越工程实践｜课程作业版本（项目简称 **CSLA**）

面向计算机本科专业课程的 AI 学习助手：**本地运行、资料不出本机、模型走 DeepSeek API**。
覆盖计算机组成原理、计算机网络、操作系统、数据结构四门课，支持带出处的问答、章节练习与错题追踪。

> 这是公开仓库。欢迎提 Issue 或 Pull Request，但**代码以 `main` 分支为准**，PR 需仓库主人合并后才生效。

## 现在能做什么

| 功能 | 说明 |
|---|---|
| **资料 RAG 问答** | 导入课件/笔记 → 切片建索引 → 回答带 `[c1]` 编号；服务端会校验编号合法性，编造引用会被标红 |
| **科目学习** | 4 科 19 章，大纲 → 讲解 → 单选题 → 判分 → 章节小结；答错自动进「易错本」 |
| **AI 一句话改软件** | 资料管理与科目学习页各有一个指令框，模型通过 15 个工具查/移/删资料、按科目归类、抓网页、增删改章节（删除类操作强制二次确认） |
| **资料管理** | `核心资料 core` + 四学科文件夹，点击直接打开源文件，文件夹支持「保留资料」与「连资料删除」两种删法 |
| **个人信息** | 年龄/性别/专业/需求四栏目（注入讲解提示）＋ 按月学习者档案 |
| **近期总结** | 对话总结、章节小结、易错提示本，卡片点击放大查看 |
| **界面** | Canvas 粒子欢迎页（鼠标跟手水波纹）→ 首页「今天学点什么？」→ 五个功能页 |

## 两个版本，两个分支

| 分支 | 目录 | 说明 |
|---|---|---|
| **`main`** | `AIassistant/` | **本体**。纯 Python 标准库 + 原生 JS，零第三方依赖 |
| `gpt-version` | `AIassistant/` + `AIassistant2/` | 另一 AI（GPT）写的平行版本，与本体的快照并存 |

两套实现互不干扰；只看本体请留在 `main`。

## 三步跑起来

```powershell
# 1. 进目录，双击启动脚本（会自动找 Python、开浏览器）
AIassistant\启动.bat

# 2. 打开 http://127.0.0.1:8737 ，填 DeepSeek API Key
# 3. 进主界面，先在「资料管理」导入资料，问答才会带出处
```

**零第三方依赖**：后端只用 Python 标准库（`http.server` + `sqlite3` + `urllib`），前端原生 JS，不需要 `pip install`，Python 3.10+ 即可。

没有 API Key 也能先看界面：

```powershell
cd AIassistant\app
python server.py --mock --open     # 离线演示模式，模型输出为占位文本
```

关闭最后一个浏览器页面约 25 秒后，服务会自动停止，控制台窗口随之退出。

详细说明见 **[AIassistant/README.md](AIassistant/README.md)**。

## 协作约定

- `main` 保持可交付状态；改动走分支 + Pull Request，合并前至少一位队友 Review
- 分支命名：`docs/<模块>`、`code/<模块>`、`fix/<问题>`
- 提交信息：`<类型>: <说明>`，类型限 `feat` / `fix` / `docs` / `chore` / `refactor` / `test`
- 提交前跑轻量检查：`cd AIassistant\app && python check.py`（不调模型、不写库）
- 细节见 `文档/队友协作指南.md`（含 SSH 配置、克隆、冲突处理）与 `AGENTS.md`
