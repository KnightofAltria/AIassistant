# AIassistant

北京理工大学大四卓越工程实践

计算机课程学习助手（项目简称 **CSLA**）：面向计算机本科专业课程与计算机前沿内容的 AI 学习助手。课程作业版本，目标是**功能具备、流程能演示、代码能安装、文档与实际一致**，不追求产品化与算法创新。

## 目录结构

```
卓越/
├── AIassistant/                          # 项目代码
│   └── AIassitant/需求简述.txt
├── 文档/                                  # 全部文档资料
│   ├── 课程要求/                          # 课程安排、课件、九份模板、任务成果
│   ├── 计算机课程学习助手_交付文档初稿/        # 九份项目文档、补充交付、工作记录
│   ├── 一种方案/                          # 设计文档 v1.1（15 篇）
│   └── _文档生成/                         # 生成/修订文档的 Python 脚本
├── 日志/                                  # 每日修改日志（YYYY-MM-DD 修改日志.docx）
├── AGENTS.md                             # 项目常驻约定（每日日志制度、提交规范）
├── .gitignore
└── README.md
```

| 路径 | 内容 |
| --- | --- |
| `AIassistant/` | 项目代码，当前仅有需求简述，源代码待开发 |
| `文档/课程要求/` | 课程安排、课件、九份文档模板、任务成果与编写指南 |
| `文档/计算机课程学习助手_交付文档初稿/` | 九份项目文档、补充交付材料、工作记录（周报/会议/测试/缺陷）与 HTML 阅读版 |
| `文档/一种方案/` | AI 学习助手设计文档 v1.1：需求、架构、数据、RAG、接口、部署、测试等 15 篇 |
| `文档/_文档生成/` | 生成与修订交付文档的 Python 脚本 |
| `日志/` | 每日修改日志，一天一个 Word 文档，由 `文档/_文档生成/make_daily_log.py` 生成 |

> 空目录不会被 Git 记录。`任务一：PPT/` 目前只保留在本地，需要纳入仓库时在目录里放一个 `.gitkeep`。

## 协作约定

**分支**

- `main` 始终保持可交付状态，不直接提交
- 每人从最新 `main` 开分支：`docs/<模块>`、`code/<模块>`、`fix/<问题>`
- 通过 Pull Request 合并，合并前至少一位队友 Review

**提交信息**：`<类型>: <做了什么>`

```
docs: 补充需求规格说明书第 3 章
code: 实现课程知识检索接口
fix: 修正测试用例编号重复
```

**提交前自检**

1. `git pull` 同步最新代码
2. `git status` 确认没有 `__pycache__/`、`~$*.docx` 这类临时文件
3. 大文件（课件 PDF、压缩包）已在 `.gitignore` 中忽略，不要强行提交
