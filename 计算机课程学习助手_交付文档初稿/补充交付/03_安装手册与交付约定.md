# 安装手册与交付约定

本手册是开发应落实的交付约定，当前没有对应源码和运行包。以下目录命令未验证，不是现成可运行程序。第7周由另一成员实测后改正式手册。

## 1 目标目录

```text
cs-learning-assistant/
  backend/app/main.py
  backend/requirements.txt
  frontend/package.json
  frontend/package-lock.json
  scripts/init_db.py
  scripts/import_demo.py
  scripts/backup.py
  scripts/restore.py
  data/
  models/
  .env.example
  README.md
```

未实现的脚本不可留在最终操作步骤。

## 2 环境与配置

API需Python、Node和网络；本地另需生成与嵌入模型。版本第一周验证后锁定。API不要求GPU，模型资源预算见方案。

| 配置 | 用途 |
|---|---|
| APP_HOST/APP_PORT | 业务地址端口 |
| DATABASE_PATH | SQLite路径 |
| MODEL_MODE | api/local |
| API_BASE_URL/API_MODEL/API_KEY | 服务端API配置，不入Git或前端 |
| LOCAL_MODEL_URL | 本机推理服务 |
| EMBEDDING_MODEL_PATH | 已下载BGE |
| SESSION_SECRET | 实例随机密钥，不能公共默认 |
| SOURCE_ALLOWLIST | 固定来源 |

## 3 拟定启动步骤

创建虚拟环境，安装依赖，复制.env.example填配置，初始化并导入样例，构建前端，由后端提供静态页面。拟定Windows命令如下，开发后逐条验证：

```text
python -m venv .venv
.venv\Scripts\python -m pip install -r backend/requirements.txt
.venv\Scripts\python scripts/init_db.py
.venv\Scripts\python scripts/import_demo.py
cd frontend
npm ci
npm run build
cd ..
.venv\Scripts\python -m uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000 --workers 1
```

仅局域网按需用0.0.0.0并限制防火墙；个人使用127.0.0.1。保持单worker避免重复定时任务。首次设置自己的管理员密码，不分发固定口令。

## 4 本地模型

先单独验证推理服务再配LOCAL_MODEL_URL。微调用同基座及PEFT适配器，不默认能导入Ollama。模型端口绑定本机，本地模式提前下载生成与嵌入模型，断网验证且禁止云后备。

## 5 安装验收

非编写者在另一设备从交付包开始，记录环境、命令、错误及修复。验证登录导入问答练习更新和重启，手机通过主机IP操作。未通过不能写成功。

## 6 备份恢复与停止

备份脚本使用SQLite backup并保存资料、版本与配置说明。恢复先停业务，保留原副本，在测试目录核对，不覆盖唯一数据。停止服务后按用户选择保留数据，不卸载共用Python/Node。

端口冲突改端口；缺依赖按锁文件安装；模型先单独检查；手机查IP网络防火墙。最终替换为实际路径和可复现命令。
