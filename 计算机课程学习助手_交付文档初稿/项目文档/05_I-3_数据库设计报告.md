# 计算机课程学习助手数据库设计报告

标识CSLA-SD-DB；版本0.2；日期2026-10-24；主责B；状态初稿，待评审。版本历史：0.1以12张表替代原复杂数据模型。

版本历史：0.2 新增本科专业课程与计算机前沿范围，统一试点、来源元数据和验收。

## 0 文档介绍

规定数据、关联与约束，供实现和测试使用。参考需求和模块设计。范围为SQLite单实例。ID为整数主键，时间存UTC ISO字符串，展示用Asia/Shanghai。

## 1 环境

拟使用data/app.db及SQLAlchemy，开启foreign_keys并按测试设置busy_timeout。仅一个业务进程，保持写事务短，不在事务中等待模型和下载。

## 2 命名

小写snake_case；id为主键，xxx_id为外键，created_at为创建时间。下列未标可空的业务字段均非空；未列默认值的由服务端提供。JSON使用TEXT存储并校验结构。枚举使用CHECK约束。

## 3 逻辑设计

```text
users ──< sessions
users ──< conversations >── courses ──< documents ──< chunks
conversations ──< messages
users ──< attempts >── questions >── courses
courses ──< sources ──< update_candidates
courses ──< notifications
```

通知属于课程，首版不逐人存已读。错题和建议由attempts计算，无需单独画像表。

## 4 物理设计

### 4.0 表汇总

| 表 | 用途 | 核心约束 |
|---|---|---|
| users | 测试用户 | 用户名唯一、角色限定 |
| sessions | 登录会话 | 令牌摘要唯一、有效期 |
| courses | 课程 | code唯一 |
| documents | 文档及版本 | 课程+内容哈希唯一 |
| chunks | 切片与向量 | 文档+序号唯一 |
| conversations | 用户课程会话 | 用户与课程外键 |
| messages | 一轮问答 | 会话+请求键唯一 |
| questions | 版本化单选题 | 有效答案与知识点 |
| attempts | 作答与重做 | 用户+提交键唯一 |
| sources | 固定网络来源 | 课程+URL唯一 |
| update_candidates | 审核候选 | 来源+哈希唯一 |
| notifications | 更新摘要 | 发布文档唯一 |

### 4.1 users和sessions

users：id INTEGER PK；username TEXT唯一，长度3–32；password_hash TEXT；role TEXT CHECK student/admin；created_at TEXT。使用Argon2id等专用密码哈希，不保存可逆密码。

sessions：id INTEGER PK；user_id INTEGER FK users；token_hash TEXT唯一；expires_at TEXT；created_at TEXT。退出删除会话，过期拒绝。令牌由安全随机数生成。

### 4.2 courses和documents

courses：id INTEGER PK；code TEXT唯一；name TEXT；description TEXT；kind TEXT CHECK course/frontier，默认course；created_at TEXT。前沿专题复用此表，不新增学科平台。初始code为DS（数据结构）、DB（数据库基础）、AI_FRONTIER（大模型与RAG前沿专题）。

documents：id INTEGER PK；course_id INTEGER FK；title TEXT；storage_path TEXT可空；origin_url TEXT可空；source_published_at TEXT可空；source_updated_at TEXT可空；fetched_at TEXT可空；applicable_version TEXT可空；content_hash TEXT；version INTEGER默认1；status TEXT CHECK processing/active/failed/withdrawn；error_message TEXT可空；created_at TEXT。唯一(course_id,content_hash)。重复导入返回已有记录。撤回保留定位和状态，旧引用显示撤回。

### 4.3 chunks

id INTEGER PK；document_id INTEGER FK；ordinal INTEGER；text TEXT；locator TEXT JSON含page或paragraph；embedding BLOB；embedding_model TEXT；dimension INTEGER默认512。唯一(document_id,ordinal)。

向量统一float32，校验字节数dimension×4，保存模型完整版本指纹，不混用空间。查询JOIN documents并过滤课程及active；按同序绑定向量与chunk ID，不加载不可信pickle。

### 4.4 conversations和messages

conversations：id INTEGER PK；user_id INTEGER FK；course_id INTEGER FK；title TEXT；created_at TEXT。

messages：id INTEGER PK；conversation_id INTEGER FK；request_key TEXT；question TEXT；answer TEXT可空；citations_json TEXT默认[]；status TEXT CHECK pending/completed/failed；model_route TEXT；created_at TEXT。唯一(conversation_id,request_key)。每行一轮问答，引用保存chunk_id、定位及标题，读取时再次检查课程和状态。

### 4.5 questions和attempts

questions：id INTEGER PK；course_id INTEGER FK；kp_code TEXT；stem TEXT；options_json TEXT；correct_option TEXT CHECK A/B/C/D；explanation TEXT；version INTEGER默认1；active INTEGER默认1且限定0/1。已被作答的题目不覆盖修改，更新时创建新版本记录。

attempts：id INTEGER PK；user_id INTEGER FK；question_id INTEGER FK；submission_key TEXT；selected_option TEXT CHECK A/B/C/D；is_correct INTEGER限定0/1；is_first INTEGER限定0/1；created_at TEXT。唯一(user_id,submission_key)。对(user_id,question_id)建WHERE is_first=1部分唯一索引，保证并发也只有一条首次作答。

重做新增记录，不覆盖首次结果。首次错题的最近作答答对显示已复习，再错可重新待复习；首次正确率不被重做抬高。

### 4.6 sources和update_candidates

sources：id INTEGER PK；course_id INTEGER FK；url TEXT；allowed_host TEXT；last_hash TEXT可空；last_checked_at TEXT可空；enabled INTEGER默认1。唯一(course_id,url)。来源通过服务端固定配置，不给学生任意URL抓取能力。

update_candidates：id INTEGER PK；source_id INTEGER FK；content_hash TEXT；title TEXT；body TEXT；summary TEXT可空；status TEXT CHECK pending/approved/rejected；published_document_id INTEGER FK documents可空；reviewed_by INTEGER FK users可空；reviewed_at TEXT可空；created_at TEXT。唯一(source_id,content_hash)。只有pending可批准；解析失败保持pending并显示原因。

### 4.7 notifications

id INTEGER PK；course_id INTEGER FK；document_id INTEGER FK且唯一；title TEXT；summary TEXT；created_at TEXT。撤回后显示撤回标记，文档不再检索。

## 5 安全性设计

浏览器不访问数据库文件；私人记录按登录用户过滤，不接受客户端user_id冒充身份。管理员维护公共内容，不因此自动开放私人对话。

作答在一个事务中查提交键、读题目、评分、写首次/重做；唯一冲突读取已有结果。审核先在事务外解析及嵌入，成功后事务写文档、切片、候选状态及通知，重复审核返回已有结果。

本人清除限制user_id，事务删除其messages、conversations和attempts，不动公共内容。清除时取消本人未完成请求，写回前核验会话仍存在，防止数据被旧请求复活。

## 6 优化

索引documents(course_id,status)、conversations(user_id,course_id)、attempts(user_id,question_id,created_at)、questions(course_id,active)、update_candidates(status)。约1000切片内先用线性点积，超规模再实测评估向量索引。

## 7 管理维护

迁移脚本随版本提交，样例导入幂等。备份用SQLite backup接口并复制资料目录；恢复停写，核对账号、资料、作答和引用。更换嵌入模型后重新计算全部向量，不直接混用旧向量。

## 8 前沿元数据补充

update_candidates增加source_published_at、source_updated_at、fetched_at、applicable_version字段，TEXT类型，其中原文日期和版本可空，fetched_at由抓取服务填写。批准时复制到documents；notifications引用document_id读取相同元数据，避免重复保存造成不一致。缺少来源日期不以抓取日期冒充。
