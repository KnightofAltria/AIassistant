# 接口与流式协议设计

## 公共约定

基础路径/api/v1，JSON使用snake_case；身份使用服务端会话HttpOnly、Secure、SameSite=Lax Cookie，跨站写入需CSRF令牌并校验Origin。同源部署为默认，禁止开放任意CORS。写操作均要求X-CSRF-Token，登录页先GET /session获取CSRF上下文。客户端提供user_id一律不用于授权。

ID为UUID，时间为RFC3339 UTC。列表用limit（1至100，默认20）及opaque cursor，响应含items、next_cursor。所有响应设置X-Trace-Id。错误对象含code、message、trace_id、retryable、details；details不含密钥、文件系统路径或他人记录。

400请求错误，401未登录，403角色不足，404资源不存在或不可访问，409版本/幂等冲突，413过大，422字段不合法，429限流，503依赖不可用。流建立后的错误通过SSE事件报告，不能再依赖HTTP状态改变。

## 问答请求与SSE

创建请求示例：

```json
{"text":"相关是否意味着因果？","mode":"hint_first"}
```

返回202：

```json
{"request_id":"b76c3ddb-b371-4b9c-a203-fd2e95076167","status":"queued","events_url":"/api/v1/requests/b76c3ddb-b371-4b9c-a203-fd2e95076167/events"}
```

SSE Content-Type为text/event-stream，禁用反向代理缓冲和响应缓存，每15秒发送注释心跳。真实模型token增量到达才转发delta，不先等完整生成再切段伪装实时。

```text
id: 1
event: status
data: {"stage":"retrieving"}

id: 2
event: delta
data: {"text":"相关关系本身不能证明因果。"}

id: 3
event: citations
data: {"verification":"passed","items":[{"citation_id":"c1","label":"统计基础 第2章","locator":{"page":12}}]}

id: 4
event: completed
data: {"message_id":"8495f205-7890-41cc-9bdb-1e0674893f9c","snapshot_id":"88e3fc7f-00ba-4aa9-96d2-7ad8c8fe6198","status":"completed"}
```

示例中c1仅为可读缩写；正式引用ID必须UUID。状态stage为queued、retrieving、generating、verifying。终结事件只能出现completed、failed、cancelled之一。failed含code、message、retryable；完成事件前只显示待核验文本，不能据此记录已确认学习结论。

事件ID在请求内单调递增，保留最近10分钟可回放事件。Last-Event-ID过期返回410，由前端GET请求状态并显示最终结果；无法回放时不能重新生成或重复计费。前端按ID去重，支持UTF-8跨字节分块和多行data，不按网络chunk直接当JSON。请求对象和最终消息至少按学习记录留存策略保存。

## 幂等与版本

问答、抓取、发布、提交作答需幂等，幂等记录至少24小时。作用域为用户+路径+key；相同body重试返回原对象，相同key不同body返回409。attempt的client_submission_id长期保持唯一，因此离线重连超过24小时也不重复计分。

审核和发布必须携带expected_revision；构建任务保存被审核候选版本和课程快照。取消请求幂等，已完成后取消返回当前终态。删除和导出也必须去重，下载链接10分钟失效并再次鉴权。

## 结构化评分约束

Attempt请求只提交答案与提示等级；正确答案、score、user_id和knowledge_point不接受客户端覆盖。服务端从题目版本获得量规与知识点。响应score可为null，review_status=pending时不进入高置信诊断。用户异议保留原评分和后续更正版本。

hint_level由服务端提示记录校验，客户端可报告更高提示等级但不能把已见答案降为独立完成。二次认证令牌有效期5分钟，绑定用户、当前会话和敏感操作范围，一次成功使用后失效；密码不写入审计正文。令牌获取、导出文件下载和后台配置管理的具体界面随模块实现补齐，不能省略相应权限检查。
