# 知序 CSLA 计算机学习助手

按仓库根目录 `设计文档.txt` 制作的 PC 本地交付演示版。独立于 `AIassistant`，使用自己的代码、端口和数据目录。只接 DeepSeek API，不提供账号登录、本地模型或手机端。

## 启动

双击本目录的 **`start.bat`**。已安装 Python 3.10 或以上即可，不需要 pip、Node.js、数据库服务或前端构建。启动后自动打开浏览器：

**http://127.0.0.1:8766**

首次点「开始学习」进入 API 设置。填写自己的 DeepSeek Key，保存后进入首页；也可以先进入本地学习模式阅读讲义、做题和管理文件。AI 功能没有 Key 时会明确提示，不会返回伪造答案。

命令行启动：

```powershell
cd assistant2
python server.py
```

其他启动选项：

```powershell
python server.py --port 8767
python server.py --no-browser
python server.py --data-dir D:\CSLA-data
```

关闭服务窗口或按 Ctrl+C 停止。关闭浏览器标签页不会自动停止服务。端口占用时先检查是否已经启动，或使用其他端口。建议 Windows 10/11、Edge/Chrome、1280×800 及以上窗口。

## 已实现的学习流程

1. 欢迎页：流场粒子、稀疏科技连线、鼠标波纹、延迟出现的「开始学习」按钮；支持系统减少动态效果偏好。
2. 首页：今天学点什么、五个功能入口、课程进度、待复习题数、最近作答记录。所有统计来自本机实际记录，初次使用没有虚构的学习时长或进度。
3. 个人信息：昵称、自定义图片头像、年龄、性别、专业、学习需求与目标。用户主动填写的信息用于 AI 讲解上下文。可生成多份按月份命名的近期档案，包含真实练习记录和近期提问。
4. AI 聊天：多会话、重命名、删除、科目选择、多轮上下文、本地资料检索、引用片段、Markdown 代码块、失败后保留输入、Ctrl+Enter 发送。每轮成功回答会自动更新本地对话摘录；上方「查看总结」可打开或重新生成 AI 归纳。
5. 近期总结：对话、练习、档案分类浏览，Markdown 导出和删除。易错提示本可重新答题，正确后标记「本次复习通过」。
6. 科目学习：数据结构、操作系统、计算机网络、计算机组成原理共 12 个初始章节、36 道原创客观题。讲义包括概念、推演例子和易错点。服务端评分、自动总结和错题归档。初始科目不可删除，初始章节删除前提醒。可增加自定义科目、手动编辑讲义、由 AI 生成章节与练习。底部提问结合当前章节，记录同步到聊天页。
7. 资料管理：按文件夹浏览和搜索，导入 TXT/MD/DOCX/PDF，预览文字、下载原件、新建和删除空文件夹、拖动或显式移动文件、删除文件。可用自然语言提出整理要求，AI 输出移动建议，经核对后一键执行。
8. 来源：预置 12 份原创讲义和 3 份实际采集的开放教材文字；提供四个公开教材/视频入口，可收录来源导航卡。`core` 文件夹中的文字可用于所有科目的检索，其他资料按所选科目过滤。

## 五分钟演示路线

1. 启动，观看欢迎页，点「开始学习」，保存 API 配置或先跳过。
2. 首页进入数据结构 → 线性表、栈与队列 → 章节练习。
3. 三题分别选 A、A、B，交卷应为 2/3；查看解析，再进入近期总结。
4. 打开易错提示本，第一题重新选 C，验证后显示本次复习通过。
5. 资料管理导入一份 Markdown 笔记，点击预览，把它拖到数据结构文件夹。
6. 配置 Key 后在聊天页选择数据结构，询问「解释栈和队列」；查看资料引用和对话总结。
7. 添加「数据库系统」科目，生成入门课程，编辑一个章节；在个人信息页生成近期档案。

## 数据、隐私和备份

默认所有可变数据均在 `assistant2/data/`，不会修改 `AIassistant` 的数据：

```text
data/
  assistant.sqlite3       课程、会话、作答、档案、文件夹等元数据
  files/                  上传原件和可检索文字资料
  近期总结/               每份对话/练习/档案的 Markdown 文件
  学习者档案/             按月份生成的独立档案
  credentials.json        仅勾选「记住 Key」时生成
```

默认 Key 只在服务进程内存中保存，重启需重新填写；也支持 `DEEPSEEK_API_KEY` 环境变量。选择记住后为本机明文文件，请勿共享。整个 `data/` 已被 Git 忽略。个人信息页可导出学习记录 JSON，导出不含 Key，但包含对话和资料提取文字，应视为个人数据。上传原件不在该 JSON 内。

完整备份：先停止服务，再复制整个 `data/`；恢复时停止服务，把备份放回相同位置。对外分发程序时**不要携带 data/**。数据目录可用 `--data-dir` 指定，默认遵循设计文档保存在程序目录。

服务只监听 127.0.0.1，无账号体系，供本机单人使用。不要通过反向代理将其暴露到公网。写接口验证 Host、Origin 和本次服务启动的随机请求令牌。上传文件使用随机内部文件名，不能指定保存路径；限制大小和 DOCX 解压尺寸。

## 实际边界

- DeepSeek 使用官方 `/chat/completions` 接口，默认模型名 `deepseek-flash`，设置中可修改。接口依据 2026-10-24 官方文档。回答为整段返回，当前未实现流式显示或中断上游生成。
- 本地检索为中文双字片段和英文词的词法检索，按科目加 core 过滤，再选最多 4 个片段。不是向量数据库，也未声称达到正式 RAG 评测指标。
- TXT/MD 支持 UTF-8 和 GB18030；DOCX 提取正文段落。PDF 只保存原件，不做 PDF 文本解析或扫描件 OCR，界面明确标识未索引；需额外导入文字版参与检索。单文件最大 8 MB，提取文本最多 300000 字符。
- 公开教材采集脚本只访问固定的开放授权来源。新增科目不会自动爬取未知网站，模型也不会自主联网搜索。页面提供可靠来源导航、手动导入及 AI 内容生成，未把导航卡冒充完整教材。
- 初始讲义和题目为本次编写的教学示例；AI 新生成题目会做结构校验，但其知识准确性仍需核对。没有模型训练、正式数据集、正式学情诊断或能力认证。
- AI 资料整理只执行经过用户核对的文件移动，不允许修改程序代码。章节可手工编辑或通过主题生成新章节，普通聊天不会自动执行破坏性操作。
- 文件夹是应用内逻辑分类；源文件以随机名保存在 files/。预览显示文字，下载通过浏览器完成，不会自动启动本机任意程序。
- 本版只有 PC 验收，不包含安卓或手机适配交付。

```powershell
python -m unittest discover -s tests -v
```

2026-10-24：16 项后端测试通过，覆盖评分及防重复、错题复习、科目保护、导入/解析/移动/删除、课程检索隔离、Key 不回传、无 Key 不伪造回答、生成内容结构校验、持久化及 HTTP 请求保护。涉及 AI 内容的自动测试明确使用模拟响应，不等于真实 DeepSeek 联调。

浏览器验收使用 `tests/ui.cjs`，需要单独安装 Playwright 并使 Node 能找到该包（运行程序本身不需要这些依赖）：

```powershell
node tests/ui.cjs
```

已在 Windows Edge 的 1440×1000 和 1280×800 窗口验证：启动引导、首页、练习评分、总结、错题复答、资料导入预览移动、无 Key 时保留输入、档案持久化、自定义科目与章节、无页面脚本错误和整体横向溢出。测试启动独立数据目录，不写入用户学习数据。截图与详细报告位于忽略的 `test-results/`。
