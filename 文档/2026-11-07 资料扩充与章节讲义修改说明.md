## 本次解决的问题

此前资料主要依靠少量内置大纲，整章讲解提示限制为600字，难以支撑系统学习。本次增加按文件夹管理的主要参考文献、官方教材与中文补充指南，支持按教材目录建立章节，将完整讲义按教学单元分别生成并保存。

## 主要功能与操作

1. 在“资料管理”选择科目文件夹，上传PDF、Word或Markdown并勾选“主要参考文献”；已有资料也可直接设为参考文献。
2. 在教材卡片点击“目录与生成章节”，核对页码、标题与层级。系统读取PDF书签或正文标题，识别不足时可手工补充。
3. 选择本科目，预览按大章或小节生成的章节，再确认追加。相同完整章节路径跳过，已有章节、大纲、讲义和题目保留。
4. 在“科目学习”进入章节，点击“生成完整讲义”。界面显示分节进度，完成后可通过目录导航、引用页码阅读教材并下载Markdown讲义。
5. 普通学生不能修改核心文件夹资料；待审核资料不能参与参考检索。数据继续按账号隔离。

目录每条可填写标题、PDF阅读器页码及层级；最多512条，层级1～6，未知页码填0。相同标题位于不同大章时使用完整路径区分。教材新增章节重启后仍可编辑，不会被误标为内置章节。

## 资料来源与分发

官方PDF包括UC Davis的Below C Level、Dordal计算机网络教材、MIT xv6、Open Data Structures、Erickson Algorithms与两份专题讲义、Kuphaldt数字逻辑全卷、11份OSTEP专题及RFC 1034/9293/9110。目录、官方地址、许可说明、SHA-256和页数记录在app/reference_catalog.json。

本地已核验22份PDF，合计45969992字节（约43.8MiB），共3212页；1497个目录条目包含中文主章与原文小节。PDF原件及提取缓存位于app/reference_library/，被Git忽略。GitHub提供目录、校验数据与官方下载功能，不包含教材PDF副本。

首次检出代码时，在科目文件夹展开“添加官方教材与专题PDF”，筛选科目后下载导入；下载仅接受目录中已核验的官方地址、版本哈希及32MB限制。官网文件换版或暂时无法访问时会提示失败，需要更新目录校验信息或改为手工导入。

四份中文补充指南随源码分发，位于app/study_guides/，共29个专题、20188字符，包含逐步例题、公式、代码、易错点和自测解析。指南标注为AI辅助编写的项目资料并附原始参考链接。PDF和指南按账号独立导入；用户删除或移出后，启动不会自动恢复。

旧账号已导入四本教材时，可用“导入已下载PDF”刷新细化目录，复用原资料；手工修改过目录的用户应先保存自己的版本。

## 完整讲义生成与保护

每个教学单元包含“学习目标与前置知识、概念与原理、公式或实现步骤、例题与逐步解析、易错点与自测解析”五类内容。真实输出不足700个非空白字符、缺标题、代码块未闭合、模型截断或引用不存在的编号时，本轮不保存。

每章只允许一个生成任务，整章成功后一次性写入lecture与lecture_meta。失败、连接提前断开或生成时切换账号不会覆盖已有完整讲义。检索优先保留教材章节页范围，再选同文件夹相关补充资料，最多6份，上下文最多14000字符。

生成检查保证结构和保存完整性，不能代替逐条事实核验。整章会触发多次模型调用，耗时与费用取决于模型服务；本次未调用真实DeepSeek模型。演示模式的内容明确标为演示，不作为学习材料。

## 本地启动与展示顺序

Windows可双击AIassistant-integrated/AIassistant/启动.bat。macOS在仓库根目录运行：

```bash
python3 AIassistant-integrated/AIassistant/auth_server/auth_server.py
```

另一个终端进入AIassistant-integrated/AIassistant/app后运行：

```bash
python3 server.py --open
```

访问http://127.0.0.1:8737，注册或登录，再填写DeepSeek API Key。要演示界面流程，在启动命令中加--mock；要使用正式生成，去掉--mock并配置有效Key。运行只需Python 3.9+，不需要pip安装依赖。

建议依次展示：资料管理中的四科指南和官方教材入口 → 教材目录预览与小节追加 → “数据表示与运算”的26个单元 → 生成进度与讲义目录 → 引用跳转、Markdown下载与重新打开。重启集成版本并登录后，本地已缓存教材和源码指南才会导入当前账号。

## 验证结果

已在独立临时数据库和模型桩中通过check.py的34项轻量检查、test_auth.py的44项账号测试、test_references.py的19项教材与讲义测试；包含大教材上传、账号切换、失败不覆盖、目录绑定、细分章节、同科检索等场景。

浏览器验证覆盖1366px桌面与390px手机宽度、84个教材小节预览、26节演示生成、保存、下载和重新打开；无横向溢出或pageerror。系统没有Node，check.py中相关项显示跳过，另在Chromium解析全部前端JS。

中文指南中的代表性算例另行复核，KMP代码对1953组穷举文本/模式与str.find结果一致。这是针对性验证，不能解释为全部资料逐条审定。

为支持干净检出，依赖本地PDF缓存的3项测试在未缓存时明确跳过，其余16项仍可离线执行；下载教材后可运行全部19项。测试不向真实用户数据库写入数据。本次未执行selftest，未验收真实模型输出质量和真实生成耗时。
