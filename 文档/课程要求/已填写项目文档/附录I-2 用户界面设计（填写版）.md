1. 应当遵循的界面设计规范

遵循一致导航、及时反馈、可撤销优先和危险操作确认原则。沿用蓝白主题、圆角卡片与SVG图标；账号密码和API Key分开输入。权限不足时隐藏或禁用写入口，后端仍作最终校验。





2. 界面的关系图和工作流程图

界面编号：UI-01登录注册，UI-02模型设置，UI-03欢迎页，UI-04首页，UI-05聊天，UI-06科目章节，UI-07资料管理，UI-08资料阅读，UI-09总结档案，UI-10看板复习，UI-11个人信息，UI-12账号管理。

入口流程：启动 → UI-01 → 未配置时UI-02 → UI-03 → UI-04；首页与侧栏进入UI-05～UI-11。UI-07 → UI-08 → 返回列表；UI-11中的管理员入口 → UI-12。

业务流程：选择资料 → 导入反馈 → 审核通过 → 提问 → 流式回答与出处 → 阅读资料；练习作答 → 错题/复习 → 总结档案。失败保留输入并显示原因，避免把账号错误与Key校验混淆。





3. 主界面

UI-04 主界面示意：左侧为品牌、头像简介、导航和账号入口；右侧为欢迎标题、功能卡片及当前内容区。

┌侧栏────────┬主内容区域────────────────┐│头像／简介　│标题、说明、主要操作按钮　　　　　││首页／聊天　│学习卡片／科目／资料／看板　　　　││资料／档案　│列表、表单或回答内容　　　　　　　││个人／设置　│状态提示与弹窗　　　　　　　　　　│└─────────┴──────────────────────┘

点击首页卡片或导航切换视图；头像进入个人信息。设置入口维护模型Key，注销返回登录；欢迎页“开始学习”进入首页。窄屏按媒体查询调整导航和卡片列数，动画可在界面偏好中关闭。





4. 子界面A

子界面A对应UI-07资料管理与UI-08阅读。

资料管理：顶部“导入／新建文件夹／搜索筛选／排序”；中部文件夹条与权限提示；下方资料卡片、复选框和批量操作条。阅读页：标题＋返回、源文件打开/下载；下方排版/原文切换与正文。

导入支持文本、Word、PDF，提交时显示处理中并防止重复点击；卡片可编辑、移动、删除或拖入文件夹。手动排序仅在适用列表下启用。核心资料学生只读。PDF显示原版与提取文字，Word可用本机程序打开源文件。





5. 子界面B

子界面B涵盖UI-05聊天、UI-06章节学习、UI-09总结档案、UI-10看板及UI-11/12账号管理。聊天含会话列表、消息、出处、输入框和生成状态；章节页含题目、作答和反馈；档案支持月度选择与下载；看板展示复习与学习状态。个人信息维护昵称、简介和头像，支持清除本人记录；管理员管理账号启停和重置密码。清除须勾选范围并输入“确认清除”，注销须密码和用户名二次确认。







6. 美学设计

主次层级由留白、字号和色彩区分，不以装饰替代操作说明。

桌面采用固定侧栏与可滚动主区，首页用卡片组织入口；聊天突出输入与回答，阅读页突出正文。弹窗承载短表单，长文本在内容区显示。

基础色为浅背景、白面板、深正文、蓝色主操作；成功用绿色，警示用橙色，危险操作用红色。具体值以当前style.css的有效覆盖规则为准，颜色同时配合文字说明。





7. 界面资源设计

7.1 图标资源：icons.svg提供品牌、聊天、资料、文件夹、锁等线性SVG图标，通过use复用；装饰图标标记aria-hidden。

7.2 图像资源：欢迎页粒子由canvas绘制；头像来源于用户上传并压缩处理；Word资料内嵌图片仅随资料阅读展示。不依赖外部图片CDN。

7.3 界面组件：按钮、输入框、下拉框、页签、卡片、标签、Toast、弹窗、筛选条、阅读器及SSE状态区域，复用统一class。





8. 其他

验证边界：2026-11-01 Edge无界面浏览器验证进入首页且无JS异常；全部弹窗、键盘操作、窄屏和复杂资料排版尚需逐项人工验收。登录失败需区分密码错误、认证不可达及Key校验；不同副本可能连接不同账号库。
