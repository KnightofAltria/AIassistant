# 安卓全功能迁移说明

CSLA（计算机课程学习助手）｜2026-11-21｜Android 0.2.0，versionCode 3

## 本轮结果

现有 V4 的本地学习与资料管理模块已迁移到安卓工程，并生成可安装的调试 APK。覆盖资料导入与管理、参考文献、科目与章节、讲义、练习与错题、对话、总结、个人档案、看板、复习、搜索、知识图谱和文件导出。

手机继续采用 Kotlin 原生外壳、WebView 和 Chaquopy 内嵌 Python。学习服务、数据库和资料均在手机内运行，不需要电脑常驻服务。DeepSeek 生成由手机直接访问官方接口。

“迁移完成”指代码实现与本地自动化验证完成。目前没有连接实际安卓设备，也没有执行真实 DeepSeek 调用，不能将本轮结果写成全部功能已通过真机验收。自动化模型相关测试使用替代响应。

桌面云账号注册、登录、密码、跨设备会话与远程管理员功能不属于当前手机本地模式，未启用。手机本地用户可以管理自己的个人资料和共享资料；桌面管理员权限规则保留，手机账号管理接口仍拒绝访问。

## 主要补齐内容

1. 将本地共享资料管理权限从桌面账号管理员身份中分离，手机本地用户可编辑核心资料、文件夹和参考文献；桌面权限回归保持通过。
2. 大文件导入改为二进制传输，按申报长度与 32 MB 上限检查；取消、截断、超限、损坏文件不新增资料记录。解析开始后等待完成，上传超时需先查看资料列表确认结果。
3. 将偏好、页面和输入草稿保存在本地库，适配手机运行时环回端口变化；恢复时检查科目、章节、对话和资料是否仍存在。
4. 补齐无 Key 手工建科目/章节、生成下一节/全部未完成节、对话历史、中文组合输入、头像裁剪返回、图谱列表及窄屏布局。
5. 补齐 WebView 原生输入弹窗、系统文件类型选择、外部链接与 Word 报告保存；系统重建后导出使用新运行时凭据恢复请求。

## 数据与实际使用边界

学习数据库、导入原件、讲义、错题、对话和教材缓存位于应用私有 noBackupFilesDir/learning。API Key 使用 Android Keystore 的 AES-GCM 密钥加密，密文单独保存，网页只查询掩码。工程设置禁用系统云备份与迁移备份，OEM 设备实际行为仍待验收。

阅读已保存内容、手工管理资料/章节、作答已有习题和查看错题可离线使用。模型生成需要网络和 Key；请求会包含问题、对话上下文及检索资料片段。未新增 OCR 或离线大模型，扫描 PDF 仍需可提取文字。

切到后台会中断生成，在下一次响应或网络超时后检查取消，不能保证已发出的网络请求立即停止。未完成内容不会替换已保存结果，重启后运行中任务标为中断；回到章节可重试。

手机本地模式不自动同步桌面学习库，也不提供云端多用户管理。用户主动导出可以把指定文件保存或分享；卸载会删除应用内学习数据。
