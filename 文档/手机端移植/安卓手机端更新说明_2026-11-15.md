# CSLA 安卓手机端更新说明

日期：2026-11-15

版本：0.1.0 安卓本地试用版

开发分支：feat/android-local

基线提交：c6f93b4（V4）

## 1. 本次更新的结论

本次把 V4 的学习核心流程接入安卓工程，采用 Kotlin 原生外壳、WebView 界面和 Chaquopy 内嵌 Python。手机内启动只监听 127.0.0.1 的学习服务，运行时不依赖电脑或学习云后台。

用户已确定“学习资料与记录只存手机，模型可以联网”。应用按这一边界实现：学习库保存在应用私有目录；DeepSeek API Key 加密保存在手机；生成时由手机连接 DeepSeek，并发送问题、必要的对话上下文和资料片段。

当前交付是可安装的调试试用版。已完成本地自动检查、浏览器窄屏检查、安卓构建与安装包检查，尚未在安卓设备上验收，也未调用真实模型。因此不能作为经过完整验收的正式版本交付。

## 2. 已接入的功能

| 功能 | 本次实现与使用边界 |
| --- | --- |
| 本机入口 | 无需注册或登录云端账号；未配置 Key 时可进入并阅读内置资料 |
| 资料导入 | 使用系统文件选择器导入 PDF、DOCX、Markdown、文本；单文件上限 32 MB |
| 资料阅读 | 文本与 Word 内容沿用 V4 阅读流程；PDF 接入 Android 原生阅读器，支持上下页与页码跳转 |
| 目录与小节讲义 | 使用已有科目、章节与目录流程；每次生成一个小节，通过结构和引用校验后保存 |
| AI 提问 | 配置自己的 DeepSeek Key 后提问；联网请求包含回答所需的内容 |
| 习题与错题 | 基于已保存讲义出题、作答并记录错题；已有习题可离线使用 |
| 中断与恢复 | 生成任务状态持久化；应用重启后将运行中任务标记为中断，可重试未完成小节 |
| 引用与原件 | PDF 引用可以跳到相应页；外部参考链接交给系统浏览器 |
| 导出与分享 | 讲义、学习报告和源文件通过系统文件保存器导出，保存后可调用分享 |
| 手机交互 | 增加顶部目录与设置入口、窄屏样式、手机阅读和文件操作适配 |

这些功能已有代码接入及限定范围的本地验证。表中的原生设备行为仍需按第 7 节在手机上验收。

## 3. 数据存放与联网说明

| 内容或操作 | 保存位置与传输规则 |
| --- | --- |
| 资料、原件、讲义、习题、错题、对话、进度 | 应用私有 noBackupFilesDir/learning/ 下的 SQLite 与文件目录 |
| 教材缓存 | 同一私有学习目录，禁止系统自动备份 |
| DeepSeek Key | Android Keystore AES-GCM 加密；密文保存在 noBackupFilesDir/model-key.enc，Key 不写入 SQLite |
| 模型生成或提问 | 手机直连 DeepSeek 官方 HTTPS API，发送问题、必要上下文与资料片段 |
| 在线教材下载 | 联网访问所选教材来源，下载内容保存在手机缓存 |
| 打开外部链接 | 转交系统浏览器，由对应网站处理访问 |
| 主动导出或分享 | 用户指定文件交给系统保存器或分享目标，位置由用户选择 |

“只存手机”约束应用默认持久存储的位置；在线模型处理仍需要接收请求内容。未实现内容完全不外传的离线模型方案。请求在模型服务端的处理与保留规则由服务商决定，应用不能保证对方不保存请求。

应用配置关闭系统云备份和设备迁移备份，并排除 WebView 的其他应用存储。是否在目标品牌设备上完全按配置执行，还需真机检查。卸载应用会删除私有学习库；主动导出的文件可能继续保存在用户选择的位置。

本机学习服务采用随机会话凭据、Host 与 Origin 校验。API Key 在网页设置里只提供掩码，保存后清空输入框。本次未实现应用 PIN 或指纹解锁，也未自动迁移旧电脑版的账号和资料。

## 4. 安装与首次使用

设备要求：Android 8.0 及以上；支持 arm64-v8a 与 x86_64；建议先更新 Android System WebView，要求版本 100 以上。

本地交付文件：安卓试用版/CSLA-Android-0.1.0-debug.apk，约 40 MB。包名为 cn.csla.mobile，版本为 0.1.0，已通过 APK v2 签名校验。

SHA-256：

```text
71e259318a45a8dd2a611d83b9df9ef8e4f6a6c2b6f7f549f8694ff50446cb9a
```

1. 将 APK 传到手机并安装。首次安装时按系统提示允许当前文件管理器安装应用。此版本尚未上架应用商店。
2. 打开应用，进入资料页。顶部“目录”切换科目学习、对话与错题；没有 Key 也可阅读内置资料。
3. 点击“设置”，填写自己的 DeepSeek API Key，保存并校验。可在设置里清除密钥。
4. 导入一份含可提取文字的中文资料。扫描 PDF 尚未接入 OCR。
5. 进入章节，点击“生成下一节”。保持应用在前台，待完整小节校验并保存后再出题。
6. 作答并查看错题，点击来源引用核对原文；PDF 引用可跳到对应页。
7. 导出讲义或报告，选择系统保存位置；如需发送给其他应用，使用分享。

生成中切到后台会发出取消信号，在后续响应事件到达时停止；系统结束进程后也会中断。回到章节可重试未保存小节，已有讲义不应被不完整输出替换。本版不保证锁屏或长时间后台运行时继续生成。

## 8. 重建与协作

构建要求：JDK 17、Android SDK Platform 35、Build Tools 35.0.0。首次构建需要联网下载 Gradle、Android 插件及 Chaquopy 依赖。

从仓库根目录进入 android 工程，在该目录执行：

```sh
export JAVA_HOME="<JDK17路径>"
export ANDROID_HOME="<Android SDK路径>"
./gradlew assembleDebug
./gradlew lintDebug
```

构建安装包位置：android/app/build/outputs/apk/debug/app-debug.apk。其他开发机器重建时会使用自己的调试签名，不能保证能够覆盖安装本次 APK；需要覆盖升级测试时，应沿用同一签名。正式发布须使用团队管理的持久签名，不提交私钥。

在 android 目录执行以下无真实模型费用的回归：

```sh
python3 tests/test_mobile_runtime.py
python3 ../AIassistant-v4/AIassistant/app/check.py
python3 -m unittest discover -s ../AIassistant-v4/AIassistant/app -p test_lessons.py
```

浏览器交互检查另需安装 Node.js、Playwright 与 Chrome，然后执行：

```sh
node tests/test_mobile_ui.cjs
```

详细工程说明见 android/README.md。协作时从 feat/android-local 分支查看本次代码与文档；正式合并 main 前完成 Review 和验收。不要把个人 Key、签名私钥、真实学习资料、SQLite 用户库或构建缓存提交到仓库。
