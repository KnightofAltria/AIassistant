## 1 产品介绍

学生复习计算机专业课时，资料散落在课件、笔记、博客与收藏夹中，查一个问题往往要翻三四个地方，且答案来源不可追溯；做题时也缺少"错在哪、该看哪一节"的反馈。

本产品是一个**在本机运行**的学习助手：学生把自己的课程资料导入后，提问得到的回答会标注引用编号，点开即可核对原文；按科目与章节做题，系统判分并把错题收进易错本；还能用一句话让 AI 整理资料、调整章节结构。数据与资料全部保存在本机目录，模型能力通过 DeepSeek API 获取。

**业务假设**（尚待第 2 周与同学确认，未做正式访谈）：

1. 目标用户已有至少一门专业课的电子版资料。
2. 用户愿意自行申请并填写 API Key。
3. 主要使用场景是期末复习与课后补漏，而非日常连续使用。

## 2 产品面向的用户群体

| 用户群体 | 特征与使用方式 | 使用环境 |
|---|---|---|
| 计算机专业本科生（主要） | 有 1–4 门专业课资料；以提问、做题、看小结为主；单次使用 20–60 分钟 | 自己的 Windows 笔记本，本机运行 |
| 同组同学（次要） | 试用与反馈；可能同时开两个实例，需端口互不冲突 | 同上 |
| 指导教师（验收方） | 不日常使用，验收时按文档走一遍主流程 | 教学机或教师本人电脑 |

典型使用频率：备考期每周 3–5 次，平时每周 1–2 次。数据规模预期：单用户 20–100 份资料，题库数百题。

## 3 产品应当遵循的标准或规范

| 类别 | 遵循内容 |
|---|---|
| 数据交换 | HTTP/1.1；JSON（UTF-8）；流式响应用 SSE 格式，事件名 `delta` / `citations` / `completed` |
| 模型接口 | OpenAI 兼容的 `chat/completions`，支持 `stream` 与 `tools`（function calling） |
| 编码 | 全部文本 UTF-8；源码与文档统一 LF/CRLF 由 Git 归一 |
| 文件 | 资料以 Markdown/纯文本为主，原文件保留在本地目录，不转码 |
| 无障碍与兼容 | 目标桌面浏览器 Chrome/Edge 近两年版本；关键操作可用键盘完成（Esc 关闭弹窗、Enter 发送） |
| 安全 | 密钥只存本机；网页抓取限定 http/https 且拒绝内网地址 |

## 4 产品范围

**首版包含**：资料导入与索引、带引用的问答、四门课的章节学习与练习、错题与小结、工具化 AI、个人信息与学习者档案、本地安装与自动停服。

**首版不含**：登录与多用户、本地大模型推理、模型微调、原生移动 App、OCR 与多模态输入、开放题自动批改、代码执行、联网自动采集全网资料、多机同步。

**外部依赖**：DeepSeek API（可用性由第三方决定）；无 API 时可降级为离线演示模式（`--mock`），用于界面验收与流程演示。

## 5 产品中的角色

| 角色 | 可查看 | 可创建/修改 | 可删除 |
|---|---|---|---|
| 使用者（学生，本机唯一用户） | 全部资料、会话、总结、题库、错题、档案 | 资料、文件夹、科目、章节、会话、总结、错题、个人信息 | 除内置科目与内置章节之外的全部对象 |
| 模型（AI 助手） | 经检索得到的片段、当前会话上下文、科目与资料的结构 | 通过 15 个工具间接修改资料与章节；不能绕过确认删除 | 仅在被显式确认后删除资料与自定义章节 |
| 指导教师 | 只读查看代码、文档与演示 | 无 | 无 |

> 首版无账号体系，"使用者"即本机操作者；因此不做角色隔离，仅保留**内置项保护**与**删除二次确认**两道防线。

## 6 产品的功能性需求

### 6.0 功能性需求分类

| 分类 | 编号前缀 | 说明 |
|---|---|---|
| 资料管理 | FR-DAT | 导入、组织、查看、删除资料与文件夹 |
| 检索与问答 | FR-RAG | 检索、证据组装、带引用的问答 |
| 科目学习 | FR-SUB | 科目、章节、讲解、练习、判分、小结、视频 |
| 工具化 AI | FR-AGT | 自然语言指令修改资料与章节 |
| 个人信息 | FR-PRF | 基本信息、学习者档案、易错本、总结 |
| 系统与安装 | FR-SYS | 首次配置、启动、自动停服、离线演示 |

### 6.1 资料管理（FR-DAT）

| 编号 | 名称 | 功能描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-DAT-01 | 导入文本资料 | 选择本地 .md/.txt 导入，落盘到 `data/materials/`，自动切片建索引 | 必须 | 导入后 5 秒内可被检索命中；原文件出现在资料列表 |
| FR-DAT-02 | 按 URL 抓取 | 输入课程网页地址，抓取正文并入库 | 应该 | 只抽正文，不含站点导航；HTTP 4xx/5xx 给出明确提示 |
| FR-DAT-03 | 文件夹组织 | 核心资料 + 四学科文件夹；可新建、重命名、排序 | 必须 | 五个默认文件夹存在且不可删除核心资料夹 |
| FR-DAT-04 | 移动资料 | 把资料移到另一个文件夹（拖拽或指令） | 必须 | 移动后检索结果中的归属同步变化 |
| FR-DAT-05 | 打开源文件 | 点击资料直接查看原文；提供下载/在系统中打开 | 必须 | 打开内容与导入文件一致，不乱码 |
| FR-DAT-06 | 删除资料 | 单份删除，需二次确认 | 必须 | 删除后检索不再返回该资料；索引同步清理 |
| FR-DAT-07 | 删除文件夹 | 两种模式：保留资料移到根目录 / 连资料一起删 | 必须 | 两种模式行为与提示一致，删除前有明确警告 |

### 6.2 检索与问答（FR-RAG）

| 编号 | 名称 | 功能描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-RAG-01 | 资料检索 | 中文分词 + BM25 排序，支持按科目路由 | 必须 | 命中首条与问题主题一致；返回切片含出处 |
| FR-RAG-02 | 带引用问答 | 证据交给模型，回答内嵌 `[c1]` 编号 | 必须 | 回答中的编号均在本次发放范围内；点击可查看原文 |
| FR-RAG-03 | 引用校验 | 生成后校验编号与证据一致性 | 必须 | 编造编号被剔除并在界面标注 |
| FR-RAG-04 | 证据不足处理 | 检索置信度低时明确说明"资料里没有"，不得编造 | 必须 | 用库外问题提问，回答声明无依据且不出现伪造引用 |
| FR-RAG-05 | 流式输出 | SSE 逐字输出，可中途停止 | 必须 | 首字延迟 ≤ 3 秒（本机、正常网络） |
| FR-RAG-06 | 多轮对话 | 保留上下文，支持追问 | 必须 | 追问"再举个例子"能延续上一话题 |

### 6.3 科目学习（FR-SUB）

| 编号 | 名称 | 功能描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-SUB-01 | 科目与章节 | 内置四科 19 章；支持新增/删除科目与章节 | 必须 | 内置科目不可删除；自定义科目可删且提示影响 |
| FR-SUB-02 | 章节讲解 | 按章节生成大纲式讲解，可引用本科目资料 | 应该 | 讲解内容与章节主题一致，含引用或明确说明无资料 |
| FR-SUB-03 | 出题与判分 | 生成单选题、作答、判分并给解析 | 必须 | 判分与标准答案一致；答错自动进易错本 |
| FR-SUB-04 | 章节小结 | 汇总本章要点与个人错题要点 | 应该 | 小结出现在"近期总结"中且可按章节筛选 |
| FR-SUB-05 | 推荐学习视频 | 按章节给出公开课/视频检索链接 | 可选 | 只给搜索链接，不伪造具体视频编号 |

### 6.4 工具化 AI（FR-AGT）

| 编号 | 名称 | 功能描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-AGT-01 | 自然语言整理资料 | 例如"把这几份按科目分类"，调用工具完成移动/建文件夹 | 应该 | 一次指令内完成多次操作，界面显示每一步 |
| FR-AGT-02 | 修改章节结构 | 例如"给操作系统加一章 进程同步" | 应该 | 章节出现且顺序正确，内置标记不丢失 |
| FR-AGT-03 | 危险操作确认 | 删除类工具必须带 `confirm=true` | 必须 | 未确认时工具返回拒绝，不执行删除 |
| FR-AGT-04 | 抓取网页入库 | 指令里给 URL，抓正文并入指定文件夹 | 可选 | 非 http/https 或内网地址被拒绝 |

### 6.5 个人信息（FR-PRF）

| 编号 | 名称 | 功能描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-PRF-01 | 基本信息 | 年龄/性别/专业/需求四栏目，保存到本地 | 应该 | 保存后重开仍在；留空不影响使用 |
| FR-PRF-02 | 学习者档案 | 按对话与错题生成画像，按月存一份，可多份 | 应该 | 生成后可在个人信息页查看；文件存于 `data/profile/YYYY-MM.md` |
| FR-PRF-03 | 近期总结 | 对话总结、章节小结、易错提示本，可点击放大查看 | 必须 | 列表可筛选；放大后按排版显示而非 Markdown 原文 |
| FR-PRF-04 | 易错本 | 收集错题并可生成提示 | 必须 | 答错后立即出现；提示内容针对错因 |

### 6.6 系统与安装（FR-SYS）

| 编号 | 名称 | 功能描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-SYS-01 | 首次配置 | 首次打开要求填写 API Key，可测试连通性 | 必须 | 未填写时只能看到配置页；测试失败给出原因 |

| FR-SYS-04 | 离线演示 | `--mock` 模式不调用模型也能走通界面 | 应该 | 无网络/无额度时仍可演示全流程 |

| 编号 | 要求 | 验证方式 |

### 7.3 质量需求

以下为**待验证的目标**，不是已实测结果：

| 编号 | 要求 | 验证方式 |
|---|---|---|
| NFR-PERF-01 | 本机、正常网络下，问答首字 ≤ 3 秒，整题 ≤ 15 秒（500 字以内） | 实测 10 次取中位数，记录环境与时间 |
| NFR-PERF-02 | 检索 100 份资料（约 1000 切片）时单次检索 ≤ 300 ms | 计时脚本，重复 20 次 |
| NFR-REL-01 | 数据库写入失败不得导致资料文件与索引不一致：失败后索引可重建 | 人为破坏索引后运行重建命令 |
| NFR-REL-02 | 服务异常退出后重启，历史会话、资料、错题不丢失 | 强制结束进程后重启核对 |
| NFR-SEC-01 | API Key 只存本机 `data/config.json`，不写入日志、不出现在页面源码 | 全局搜索 `sk-` 前缀 |
| NFR-SEC-02 | 网页抓取仅允许 http/https，拒绝回环与内网地址（防 SSRF） | 用 `127.0.0.1`、`192.168.x.x` 测试 |
| NFR-SEC-03 | 资料与数据库不进入版本库（`.gitignore` 已排除 `app/data/`） | 检查 `git ls-files` |
| NFR-MNT-01 | 单个 `.py` 文件不超过 1200 行；新增功能优先加工具而非加页面 | 代码统计 |
| NFR-MNT-02 | 提供零成本自检脚本，日常改动 5 秒内可验证 | 运行 `check.py` |

参与者：使用者、模型（作为工具的调用者）。用例：导入资料、组织文件夹、提问并查看引用、按章节学习与做题、查看总结与易错本、用自然语言整理资料、填写个人信息、生成学习者档案。

### A.2 领域类图（核心对象）

| 对象 | 关键属性 | 关系 |
|---|---|---|
| 文件夹 Folder | 名称、是否核心、排序 | 1 : N 资料 |
| 资料 Material | 标题、科目、来源、字节数 | 1 : N 切片 |
| 切片 Chunk | 序号、文本 | N : 1 资料 |
| 科目 Subject | 名称、是否内置、排序 | 1 : N 章节 |
| 章节 Chapter | 标题、大纲、是否内置 | 1 : N 题目 |

| 错题 Mistake | 题干、我的答案、正确答案、备注 | 独立表，按科目/章节归档 |

### A.3 关键时序：一次带引用的问答

```
使用者 → 前端：输入问题
前端   → 服务端：POST /api/chat/stream（SSE）
服务端 → 检索：分词、BM25、科目路由

服务端 → 模型：system + 证据（带 [cN] 编号）
模型   → 服务端：流式文本
服务端 → 服务端：校验引用编号合法性
服务端 → 前端：delta / citations / completed
前端   → 使用者：逐字显示，编号可点击溯源
```
