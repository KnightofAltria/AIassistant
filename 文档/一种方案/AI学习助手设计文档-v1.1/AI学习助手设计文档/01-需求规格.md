# 软件需求规格说明书

版本与状态同阅读指南。产品目标是形成“课程资料问答—练习—证据积累—误区复测—资料更新”的学习闭环。

## 角色与边界

学生只访问已加入课程的公开资料、自己的学习记录与私人上传资料。课程维护者管理被授权课程的知识点、题目、来源、审核和发布，默认不能阅读学生私人对话。管理员管理账号、成员关系、模型配置与运行状态，查看原文需明确授权并留下审计记录。个人离线安装也保留学生和维护者视图，初始安装者可拥有两类角色。

课程包含标题、学科标签、教学目标、资料版本、知识点先修关系、题库和可选模型策略。学生可同时加入多门课程；会话、检索、练习和诊断必须绑定一门课程。跨课程检索留待后续明确授权设计。

## 业务需求与验收

| 编号 | 优先级 | 需求 | 可观察验收 |
|---|---|---|---|
| FR-01 | P0 | 注册登录、课程加入与切换 | 切换后会话和学习记录分别显示，越权访问失败 |
| FR-02 | P0 | PDF、DOCX、TXT、Markdown导入 | 显示解析状态、定位信息与失败原因，损坏文件不入库 |
| FR-03 | P0 | 课程内RAG问答 | 重要资料性结论附出处，点开可看到文档版本和页码或段落 |
| FR-04 | P0 | 多轮对话与教学引导 | 支持提示优先、完整解释和停止生成；缺资料时说明限制 |
| FR-05 | P0 | 练习、提交和复测 | 客观题按题库答案评分；主观题按量规输出建议及可申诉说明 |
| FR-06 | P0 | 学习事件与进度 | 同一提交重试不重复计分，设备重连后记录可查询 |
| FR-07 | P0 | 整理误区与潜在问题 | 展示证据、状态和验证题；证据不足只列待验证假设 |

| FR-09 | P0 | 定时联网收集资料 | 按课程来源列表运行，收集失败可重试，未审核不能被检索 |
| FR-10 | P0 | 审核、发布、撤回与摘要 | 对比新旧内容，发布后站内通知；撤回后新问答不能引用 |
| FR-11 | P0 | 云API与本地模型两种运行配置 | 两类环境各通过一次完整问答，本地严格模式无外呼 |
| FR-12 | P0 | 手机端和学习引导 | 手机完成加入课程、提问、查看出处、练习和查看误区 |
| FR-13 | P0 | 封装分发 | 提供版本化安装包及指南，另一台干净设备按说明启动 |
| FR-14 | P1必验 | 一门课程的领域微调实验 | 授权数据、训练配置、适配器、独立测试和基线对比齐全 |
| FR-15 | P0 | 个人数据管理 | 可导出、删除记录，退出登录后清理本设备敏感缓存 |

P0为首个可演示版本，P1必验为完整作业范围中的后续里程碑，不能在最终报告中自动省略。若课程评分规则要求微调优先，调整第12章顺序，先完成微调可行性验证。

## 关键用例

UC-01 首次学习：登录→选择或加入课程→设置学习目标→可跳过的3题摸底→首页出现“开始提问”和“建议复习”。没有测试结果时显示“尚无足够证据”。

UC-02 有依据问答：学生提出问题→系统锁定课程与知识库版本→检索可访问资料→流式显示解释→引用校验→保存回答。检索不到时给澄清问题或建议导入资料，不捏造课程出处。

UC-03 误区验证：提交练习→保存不可变作答版本→规则评分或量规建议→生成误区候选→学生查看证据→完成不同题目的复测→证据满足条件后确认或驳回→更新复习计划。

UC-04 资料更新：定时发现候选→去重和比对→维护者审核→构建待发布索引→质量检查→原子发布→向课程成员提交摘要。无变化不产生新通知。

UC-05 本地部署：安装依赖运行包→首次启动创建管理员→导入模型和课程包→选择严格本地模式→关闭网络验证问答和诊断。联网收集在离线期间暂停并提示最后成功时间。

## 非功能目标

下列均为待实测目标，测量环境见测试文档。云模式首个答案文本p95≤5秒，完整输出p95≤30秒（输入≤6000 tokens、输出≤600 tokens、5并发）；本地不预设同等速度，测试后公布硬件、模型和指标。后台索引不阻塞Web启动；问答可取消；异步任务可恢复。试运行可用性目标99%按服务端成功请求计算，观察至少7天，不等同全年SLA。

移动端360px宽度下核心页面无整体横向滚动；常用按钮触摸目标至少44px；正文16px起；键盘和读屏可完成核心操作。普通业务数据跨用户、跨课程泄露测试必须为零。学习事件入库后5秒内进入投影的目标以测试报告为准。

## 异常与限制

模型超时保存已输入内容并允许重试，不将中断答复作为正确答案。导入失败允许修复后重试；无OCR能力的扫描PDF显示“需要OCR”，不能静默成功。网络更新任务失败不影响现有已发布资料。本地推理缺少显存时提示模型不可用，不能自动转云。学生不同意云处理时使用本地配置或停止对应功能。

## 不在首版范围

手写拍照批改、语音课堂、视频解析、自动训练所有课程模型、教师班级监控、复杂社交、支付、原生App商店发行及手机端大模型推理。上述项目需要独立排期。
