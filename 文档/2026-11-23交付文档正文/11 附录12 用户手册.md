# 11 附录12 用户手册

计算机课程学习助手用户手册

1 系统使用说明

1.1 从启动到完成一次学习

1.1.1 启动与进入主界面

Windows 双击便携目录中的 CSLA.exe；macOS 在“应用程序”中打开 CSLA 学习助手。注册或切换本机账号后，配置自己的 API Key，也可先阅读资料。安卓使用手机本地用户。安装和包还原见编号 12 至 14。

1.1.2 导入与管理课程资料

打开“资料管理”，按科目导入 PDF、DOCX、Markdown 或文本。也可搜索开放教材并在“目录与生成章节”检查页码与映射。上传扫描 PDF 前先取得可提取文字的版本。

1.1.3 生成大纲与分节讲解

以复习 TCP 重传为例，先导入课件，再到科目学习打开对应章节，生成大纲和小节讲解，点击出处对照原文，完成练习并复习错题，最后在看板确认阅读和复习进度。 大纲和小节可分别重生成，已保存的讲义可以继续阅读。

1.1.4 练习、错题与学习进展

在已生成讲解的章节中选择题量（默认三题）并生成练习。每题提交后查看简要解析，需要推导过程时点击“详细解答”；可删除单题并重新生成。阅读完一节后勾选“我已阅读并理解本节”，错题进入复习记录。章节掌握度结合阅读勾选、练习完成和错题复习计算；可在“学习看板”和“近期总结”中查看进展。

1.1.5 AI 聊天与资料引用

进入“AI 聊天”，输入课程问题并发送。系统结合当前用户资料和可检索的课程资料作答；回答中的引用编号可用于核对来源。对话可继续追问、查看历史、重命名或删除。个人信息中的专业和学习需求可帮助调整讲解表达，但引用仍以实际导入资料为依据。

1.1.6 查看总结与学习看板

“近期总结”汇集对话总结、章节小结和易错提示；“学习看板”展示学习进度、掌握情况与复习入口。阅读勾选、练习和错题复习记录会影响掌握度，完成少量题目不会直接代表整章掌握。

1.1.7 设置与个人信息

在“个人信息”中维护头像、专业和学习需求；头像上传后可裁剪选定区域。“设置”采用单列布局，可调整动效、阅读排版、提示与删除确认等选项，并配置模型 API Key。切换设备或卸载手机应用前，请先导出需要保留的本地文件。

1.1.8 安卓手机使用

安卓 8.0 及以上设备安装项目 APK 后，应用在手机内部启动本地服务。顶部“目录”切换学习页面，系统返回键按科目、章节、小节逐层返回；系统文件选择器用于导入资料、保存讲义和 Word 学习报告。离线时可使用已保存内容；模型生成和在线教材下载需要联网。
