# 13 macOS安装与使用说明

CSLA 桌面版安装与使用说明

版本 0.2.0 · 2026-11-22 · Apple Silicon Mac

安装与启动

1. 从安装包分支 https://github.com/KnightofAltria/AIassistant/tree/desktop-packages-20261122 的 macOS 目录取得 DMG，然后双击打开。

2. 将“CSLA学习助手.app”拖入旁边的 Applications（应用程序）文件夹。

3. 在“应用程序”中双击“CSLA学习助手”即可使用，也可拖到 Dock 方便以后启动。

同一资料包内的“CSLA学习助手.app”也可以直接双击启动。不需要安装 Python、Node 或启动终端。关闭窗口或退出应用后，内置服务一起停止。

包面向 Apple Silicon（M1/M2/M3/M4 等）Mac，声明最低 macOS 12，实际验证系统为 macOS 26.6.2。Intel Mac 与 Windows 需另行构建对应版本。

首次使用

选择“切换 / 登录账号”，切换至“注册”填写本机账号。用户名为 3–20 位字母、数字或下划线，密码为 8–64 位且包含字母和数字。

此 Mac 第一个注册账号自动成为管理员，可维护核心资料和管理后续本地账号；后续注册账号为学生，学习数据按账号分开保存。

登录后可填写自己的 DeepSeek API Key；也可点“暂不配置，先阅读资料”，直接使用资料管理、阅读和已有学习记录。

AI 对话、章节讲解、自动出题及 AI 总结等功能需要联网与有效 Key，费用按用户的 DeepSeek 账号计费。本安装包不包含 Key。

再次启动可选择“使用默认用户”恢复已有登录，也可切换账号。

桌面版使用独立的本地账号库，与已有网页服务和安卓实例不自动同步。开发目录中的原有账号和学习资料没有打入安装包，仍保留在原位置。

常用操作

资料管理支持 PDF、Word（.docx）、Markdown 和文本等现有导入方式；源文件通过此 Mac 的默认阅读程序打开。

学习看板中“导出学习报告”会显示系统保存窗口，选择位置即可保存 Word 文件；取消保存会返回当前页面。

学习档案、原资料和讲义下载同样通过系统保存窗口处理。外部教材和视频网页用默认浏览器打开。

应用菜单“学习助手 → 打开数据目录”可查看本机数据。升级时替换 .app 文件即可保留账号和学习记录。

数据位置：~/Library/Application Support/CSLA Desktop/。accounts 保存本地账号库，learning 保存会话和各账号学习数据，reference_library 保存教材缓存，desktop.log 保存启动错误信息。备份时先退出应用，再复制整个目录。

验证与说明

资料包附“验收记录”中的自动检查结果及真实 WebKit 页面截图。运行时检查使用可删除的临时账号和数据目录，不改动用户原有资料，也未执行收费模型调用。

应用使用临时签名。使用前应核对项目交付来源和文件哈希。正式面向外部分发以签名和公证后的产物为准。

旧版 macOS 实机兼容性、人工鼠标交互和真实 DeepSeek 生成效果尚未验收。如启动异常，先查看数据目录中的 desktop.log。
