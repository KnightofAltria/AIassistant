# 12 Windows安装与使用说明

CSLA 学习助手 Windows 桌面版

版本 0.2.0 · 2026-11-22 · Windows 10 22H2 / Windows 11，64 位 x64

启动软件

1. 在安装包分支 https://github.com/KnightofAltria/AIassistant/tree/desktop-packages-20261122 下载完整 ZIP，解压后双击 Restore-Windows.cmd。它会校验并还原 Windows 安装包。已持有完整 Windows ZIP 时可直接解压。

2. 打开解压后的 CSLA-Windows-x64 文件夹，双击 CSLA.exe。第一次加载内置浏览器可能稍慢，请等待窗口出现。

3. 请保留 EXE 同级的 internal 文件夹。软件需要整个目录，不要单独复制 EXE，也不要在压缩包预览中启动。

4. 如需桌面图标，双击“创建桌面快捷方式.cmd”。快捷方式指向当前目录；移动软件后请重新创建。

软件内置 Python、界面依赖和 WebView2，无需另装 Python、Node 或手工启动服务。使用现代 Windows 自带的 .NET Framework 4.6.2 以上；目标 Windows 10 22H2 / 11 通常已具备。此包未使用商业代码签名证书，若系统显示未知发布者，请先确认文件来自本次交付、哈希一致。

首次使用

首次打开请注册本机账号。第一位注册用户为管理员，后续账号为学生；账号与学习数据按用户隔离。

登录后可选择“暂不配置，先阅读资料”，使用资料阅读、管理及已有学习记录。

AI 对话、知识讲解、出题、总结等需要联网及你自己的 DeepSeek API Key。请在配置页填写 Key；包内未放入开发者 Key。

桌面版沿用当前应用的资料、课程、问答、讲解、练习、错题、学习档案、报告及管理入口。

Word 报告、档案、讲解及原资料导出使用系统保存对话框；外部网站使用默认浏览器打开。

关闭主窗口会停止内置服务。重复双击会尝试切换到已有窗口。

数据与更新

账号、资料、Key、会话和浏览器缓存保存在当前 Windows 用户的 %LOCALAPPDATA%\CSLA Desktop\。软件菜单“学习助手 → 打开数据目录”可打开此处。

本地账号库与原网页、安卓和 Mac 实例独立，数据不会自动同步。安装包未包含旧账号、数据库、私人资料、下载书库、会话或 Key。

更新前先关闭应用，用完整新软件目录替换旧软件目录；保持上述用户数据目录即可保留记录。备份时关闭应用后复制整个数据目录，备份包含账号与 Key，请妥善保管。删除软件文件夹不会自动删除学习数据。

自检与问题处理

双击“运行自检.cmd”，可检查 Windows 架构、.NET、WebView2 加载器及本地服务。退出码 0 表示这些检查通过。

自检使用自动清理的临时账号与数据，不调用模型，不改动你的学习库。它不会打开窗口，仍需双击 CSLA.exe 检查界面。

若无法启动，先重新完整解压 ZIP，确认 internal 存在；再查看数据目录中的 desktop.log，或运行自检查看具体错误。

若窗口正常但 AI 功能失败，核对联网状态、API Key 和服务余额；资料阅读无需模型调用。
