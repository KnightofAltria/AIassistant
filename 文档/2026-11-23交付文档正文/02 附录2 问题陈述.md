# 02 附录2 问题陈述

计算机课程学习助手（CSLA）

问题陈述：

计算机专业课程知识点多、章节关联紧密，学生在阅读课件、教材和笔记时，常需要在多份资料之间反复查找。通用聊天工具虽可快速回答问题，却难以稳定给出与本课程资料对应的出处，也无法将讲解、练习和复习记录连成连续的学习过程。

本项目面向计算机组成原理、计算机网络、操作系统和数据结构等课程，建设可在本机使用的学习助手。学生可导入 PDF、DOCX、Markdown 和文本资料，按科目管理原始文件；系统解析资料并建立检索索引，在问答和章节讲解中呈现可核对的来源引用。

学生可创建科目和章节，先生成大纲，再按小节逐一生成讲解。每节讲解保存为独立 Markdown 文件，重新进入时读取已有内容；大纲和小节均可单独重新生成。界面支持折叠阅读、公式排版和按层级返回，使长篇内容便于浏览。 以复习 TCP 重传为例，先导入课件，再到科目学习打开对应章节，生成大纲和小节讲解，点击出处对照原文，完成练习并复习错题，最后在看板确认阅读和复习进度。

学习练习应以已保存讲解和资料为依据生成，标注所属小节与原始资料。学生可选择题量、作答并查看简要或详细解析，删除单题后重新生成。系统记录阅读勾选、答题和错题复习状态，据此计算章节掌握度，并在看板和近期总结中呈现学习进展。

系统需兼顾不同设备的使用方式：桌面版本提供本地资料、用户信息、对话与学习数据管理；安卓版本在手机内运行本地学习服务，通过系统文件选择器导入、保存和分享文件。模型生成功能使用已配置的 DeepSeek API；无密钥时仍可查看已保存的资料与学习内容。

系统分为以下几部分进行系统分析和设计：

1．用户信息、登录与学习偏好管理。

2．课程资料导入、分类、检索与来源引用。

3．AI 对话、章节大纲及分节讲解的生成与保存。

4．基于讲解的练习、解析、错题复习与掌握度统计。

5．学习看板、近期总结、学习报告与学习记录管理。

6．桌面及安卓端运行、设置、文件导出与数据保护。
