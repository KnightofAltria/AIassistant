1. 模块命名规则

Python文件采用小写及下划线，类采用大驼峰（Store、DeepSeekClient、AuthClient），函数/变量采用snake_case；JavaScript函数多为camelCase，DOM以稳定id关联。接口路径以/api/分组，认证服务以/auth/分组，错误包含可读说明；测试以test_前缀命名。

2. 模块汇总

2.1 模块汇总表

A 组组织学习动作，从资料入库到讲义和练习。B 组管理账号、存储及平台运行。按接口、数据与失败处理定位模块。

| 表现与学习业务子系统 | 表现与学习业务子系统 |
| --- | --- |
| 模块名称 | 功能简述 |
| app/static/*.js | 路由、账号、资料阅读、欢迎页、看板、工具流与心跳。 |
| server.py；deepseek.py；prompts.py | 路由编排、引用校验、模型调用与结构化提示。 |
| rag.py；tools.py；extras.py；pdftext.py | 解析、目录映射、检索排序和资料辅助操作。 |
| 认证与持久化子系统 | 认证与持久化子系统 |
| 模块名称 | 功能简述 |

| check/selftest/test_auth/test_answer_cache | 静态检查、mock流程、权限功能及缓存回归。 |

2.2 模块关系图

桌面或手机界面 → Python 路由 → 资料、学习或模型模块 → SQLite/Markdown。手机文件选择和桌面保存通过本机窗口桥接。

教材目录映射到章节后，生成器优先检索对应页段。讲义逐节校验和保存，习题依据已保存讲义生成并保留版本和来源。

桌面按账号检查读写权限。安卓使用手机本地角色，允许本机资料管理并拒绝桌面账号维护入口。
