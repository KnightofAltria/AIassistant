0. 文档介绍

0.1 文档目的

本文档给出计算机课程学习助手 早期版本的系统测试用例，供测试执行、回归与验收使用。每条用例包含前置条件、操作步骤、预期结果与实际结果，执行后可据此判断通过、部分通过或未执行。

0.2 文档范围

覆盖接口、功能、健壮性、性能、界面、安全、压力、可靠性与安装。保留 早期版本历史用例，并新增 7 条应用功能与多端验收用例。当前结论以 K-3 与对应环境的验证记录为准。

0.3 读者对象

测试执行人员、开发人员、项目评审与课程验收教师。执行人员应具备启动本地服务、使用浏览器开发者工具和命令行脚本的基本能力。

1. 接口－路径测试用例

1.1 被测试对象（单元）的介绍

早期版本接口与历史结果用于定位回归场景。应用各端的测试以本次交付基线、README 和新增用例为准。

1.2 测试范围与目的

覆盖注册、登录、会话、退出、科目树、资料导入、问答流、练习提交、资料移动、教材目录、管理员权限与记录清除共 14 个接口。目的是确认参数校验、状态码、权限与返回结构符合约定，异常输入不会产生副作用。

1.3 测试环境与测试辅助工具的描述

本机回环环境；使用 curl 与 Python http.client 发送请求，浏览器开发者工具查看 Cookie 与 SSE；每次执行前使用独立测试账号，涉及写入的用例在临时数据目录执行。

1.4 测试驱动程序的设计

以“准备状态 → 发送请求 → 断言状态码与响应字段 → 清理”为基本结构；认证类用例共享同一测试账号，写入类用例每条自建资料并在结束后删除。自动化部分由 test_auth.py 与 check.py 承担，手工部分按表中步骤执行。

2. 功能测试用例

2.1 被测试对象的介绍

功能测试覆盖账号与权限、资料与教材、问答与引用、科目学习与讲义、练习与错题、统计与总结、个人档案、界面设置、一句话改软件八个功能域。

2.2 测试范围与目的

保留原有功能场景，并增加分节重试与掌握度用例。以复习 TCP 重传为例，先导入课件，再到科目学习打开对应章节，生成大纲和小节讲解，点击出处对照原文，完成练习并复习错题，最后在看板确认阅读和复习进度。

2.3 测试环境与测试辅助工具的描述

桌面浏览器 1440×900 为主，必要时缩放到 390×844 与 812×375；使用测试账号 A/B 与管理员账号；模型使用 DeepSeek API，未配置 Key 时用 --mock 验证界面与流程（不评价生成质量）。

2.4 测试驱动程序的设计

手工执行页面操作，配合开发者工具查看网络请求；对判分、去重、缓存等可用接口复核；跨账号场景先退出再登录，避免浏览器缓存造成误判。
