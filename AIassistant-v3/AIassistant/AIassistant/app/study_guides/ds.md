## 1. KMP前缀表与匹配回退

### 明确数组约定

这里使用0下标前缀函数pi[i]：模式P[0..i]最长相等真前后缀的长度，pi[0]=0。不使用首项−1的next约定；两种表不能不换算就互相代入。模式ababaca的pi为[0,0,1,2,3,0,1]：在i=5的c处，候选长度3对应b不匹配，退到pi[2]=1仍为b不匹配，再退到0，故该项0。

### 可运行代码

```python
def prefix(pattern):
    pi = [0] * len(pattern)
    j = 0
    for i in range(1, len(pattern)):
        while j and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j
    return pi

def kmp(text, pattern):
    if not pattern:
        return 0
    pi, j = prefix(pattern), 0
    for i, ch in enumerate(text):
        while j and ch != pattern[j]:
            j = pi[j - 1]
        if ch == pattern[j]:
            j += 1
        if j == len(pattern):
            return i - j + 1
    return -1
```

### 跟踪与复杂度

文本abababacaba、模式ababaca，首轮连续匹配ababa后，下一个文本字符b与模式c不等。j=5回退到pi[4]=3，再与模式索引3的b匹配，文本指针不倒退；最终在起始下标2找到ababaca。前缀表O(m)，匹配O(n)，额外空间O(m)，理由是j的下降总量受之前增长总量约束，而不是简单说每个字符只比较一次。

### 自测

aaaa的pi为[0,1,2,3]。空模式本代码定义匹配位置0；单字符、文本短于模式、完全无匹配都要测。若要输出所有匹配，完整命中后将j退到pi[j−1]继续，才能保留重叠匹配；例如aaaa中aa出现于0、1、2。

## 2. 并查集与Kruskal最小生成树

### 数据结构

并查集每个集合用一棵父指针树表示，根满足parent[x]=x；find返回根，union合并不同根。路径压缩改变查找路径，按大小或秩合并控制高度，组合后多次操作的摊还复杂度为O(α(n))。这不是严格每次最坏O(1)，不能丢掉“摊还”前提。

```python
def find(parent, x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(parent, size, a, b):
    a, b = find(parent, a), find(parent, b)
    if a == b:
        return False
    if size[a] < size[b]:
        a, b = b, a
    parent[b] = a
    size[a] += size[b]
    return True
```

### Kruskal追踪

无向图边AB=1、BC=2、AC=3、CD=4、BD=5。按权排序，选AB使{A,B}合并，选BC得到{A,B,C}；AC两端已同集合，选它会成环，跳过；再选CD得到生成树AB、BC、CD，权值7。4个顶点的树恰好3条边。若图不连通，结果是最小生成森林，应报告无法构成覆盖全部顶点的一棵树。

### 正确性与自测

Kruskal选跨越当前不同连通分量的最轻边，可用割性质证明安全；并查集只判断成环，不单独证明最优。排序O(ElogE)，集合操作近线性。自测所有边权相同可能存在多棵MST，不应把某一种边序当作唯一答案；自环始终不能加入生成树。

## 3. 最短路径与关键路径的方向差异

### Dijkstra例题

有向边A→B=2、A→C=5、B→C=1、B→D=4、C→D=1。源A：初始dist(A)=0、其余∞；选A后B=2、C=5；选B后C降为3、D=6；选C后D降为4；选D结束。最短A到D是A→B→C→D，长度4。邻接矩阵实现常为O(V²)，邻接表配二叉堆通常O((V+E)logV)，不能把同一复杂度套所有实现。

### 负权反例

A→B=2、A→C=5、C→B=−4。Dijkstra可能先把B的2定为最终值，但真正经C长度1，因此一般要求非负边。Bellman–Ford允许负边并可检测可达负环；存在负环且可从源到达并通向目标时，目标最短路没有有限下界。

### AOE关键路径

DAG活动边S→A=3、S→B=2、A→T=4、B→T=6。事件最早时间ve(S)=0、ve(A)=3、ve(B)=2、ve(T)=max(7,8)=8；逆拓扑求最迟vl(T)=8、vl(A)=4、vl(B)=2、vl(S)=min(1,0)=0。活动(u,v)的e=ve(u)，l=vl(v)−w；S→B及B→T满足e=l，为关键活动，总工期8。A路径较短且有1单位余量。

### 自测

最短路径做min松弛，工期的最早事件时间做max，不能混淆。关键活动不必只形成唯一一条路径；压缩一个关键活动也不保证工期缩短同样数量，其他关键路径可能仍限制工期。邻接表的顺序影响DFS/BFS发现次序，通常不影响可达集合和无权最短距离。

## 4. 排序追踪与稳定性

### 用带身份的键测试

元素写作(2,A)、(1,X)、(2,B)，稳定排序要求最终两个键2仍按A、B顺序。仅对纯整数观察结果无法证明稳定。直接插入排序若只在a[j]>key时移动相等键，可保持稳定；若改为≥，会把后来相等元素移到前面。

### 两次具体操作

插入排序[5,2,4,1]：插入2得到[2,5,4,1]；插入4得到[2,4,5,1]；插入1得到[1,2,4,5]。已排序时采用该比较流程只需线性检查，逆序需要二次数量级移动；空间O(1)。

自底向上建大根堆[3,1,4,2]，从最后非叶索引1开始，下沉1与孩子2交换，得[3,2,4,1]；处理根3与较大孩子4交换，得[4,2,3,1]。建堆O(n)，不是把n次独立插入的O(nlogn)照搬过来；大量结点高度很低，总下沉量线性。

### 统一条件表

|算法|最好|平均|最坏|常见额外空间|通常稳定|
|---|---|---|---|---|---|
|直接插入|O(n)|O(n²)|O(n²)|O(1)|是|
|带提前退出冒泡|O(n)|O(n²)|O(n²)|O(1)|是|
|简单选择|O(n²)|O(n²)|O(n²)|O(1)|否|
|常规快速排序|O(nlogn)|O(nlogn)|O(n²)|递归栈平均O(logn)、最坏O(n)|否|
|堆排序|O(nlogn)|O(nlogn)|O(nlogn)|O(1)|否|
|常规数组归并|O(nlogn)|O(nlogn)|O(nlogn)|O(n)|是|

### 自测

快速排序遇到已排序输入是否最坏取决于枢轴选择和划分规则；大量重复键可用三路划分改善。归并相等时先取左段才能按原顺序稳定。希尔排序复杂度取决于增量序列，不能写一个没有条件的固定平均指数；计数和基数排序还依赖键范围、位数与辅助存储。

## 5. 折半与散列查找ASL

### 折半成功与失败

有序数组[1,3,5,7,9,11,13]，每次取中点，本节把一次键比较计为一个探测。成功查找判定树深度：根7为1层，3和11为2层，其余4个键为3层，等概率成功ASL=(1+2×2+4×3)/7=17/7≈2.429。失败共有8个间隙，本实现每个失败需3次探测，失败ASL=3。若把终止下标检查也计为一次比较，指标需另注明。

### 线性探测例题

表长7，h(k)=k mod7，依次插入10、17、24、31，落在槽3、4、5、6。成功探测次数1、2、3、4，等概率ASL=2.5，装填因子α=4/7。

若失败查询的初始槽0到6等概率，从各起点探测到首个空槽（计入该空槽）需要1、1、1、5、4、3、2次，失败ASL=17/7。不要只对已有键的槽位平均，也不要在遇到别的键时立即报告失败。

### 删除与边界

开放定址删除不能简单清空中间槽，否则后续冲突键的查找会过早终止，应使用删除标记或按策略重整。探测次数依赖冲突处理方法、插入顺序和概率模型；分母是题设事件数，不一定是表长或已有元素数。

### 自测

ASL不是时间复杂度；O(logn)算法仍可有具体平均比较次数。自测在上述表查找31需4次；查不存在的38从槽3开始需5次才到空槽0。线性探测会产生聚集，不能套用链地址法的平均链长公式。

## 6. 特殊矩阵压缩与地址公式

### 下三角矩阵

n阶下三角矩阵含对角线，按行存储且下标从0开始，元素(i,j)满足0≤j≤i<n，在压缩数组中的位置k=i(i+1)/2+j。因为第i行之前有1+2+…+i个元素。若从1开始编号，公式会变成i(i−1)/2+(j−1)，不能只改i不改j。

### 两题

5阶矩阵的(3,1)按0下标，k=3×4/2+1=7；每元素4B、首址1000，则地址1028。总需5×6/2=15个元素，60B。对称矩阵只存下三角，访问(1,3)先交换为(3,1)，仍取同一槽7。

若是上三角按行存储，在第i行前有n+(n−1)+…+(n−i+1)=in−i(i−1)/2个元素，再加本行偏移j−i。n=5、(1,3)得k=5+2=7。同样的数值在本例只是巧合，不能把下三角公式用于所有上三角元素。

### 稀疏矩阵

三元组存(行,列,值)，需要知道按行还是按列排序；快速转置可统计每列非零数并求前缀起始位置，复杂度通常O(列数+非零数)，额外O(列数)。若两个非零元共享位置，要按输入规范合并或拒绝。

### 自测

三角矩阵与对称矩阵的未存位置含义不同：对称位置可映射，严格三角外常是0或统一常量。压缩省空间不代表所有运算都O(1)。自测n=4下三角共10元素，(2,2)映射5。

## 7. 哈夫曼编码与树的重建

### 贪心合并追踪

权值2、3、7、8，每轮合并最小两棵树：2+3=5；5+7=12；8+12=20。内部合并权值之和5+12+20=37，等于叶结点加权路径长度WPL。叶8深度1，叶7深度2，叶2和3深度3，WPL=8×1+7×2+2×3+3×3=37，两种算法互相验证。

### 编码并不唯一

若根的8放左边、其余放右边，可令8=0、7=10、2=110、3=111。没有一个码字是另一个码字的前缀，因而可即时解码；左右孩子互换会改变码字但不改变WPL。等权合并也可能产生多种最优树，不能说码字唯一。

### 二叉树重建

前序ABDCE，中序DBAEC，且标签互异：前序首项A是根，中序A左侧DB属于左子树、右侧EC属于右子树。左子树前序BD、中序DB得到B的左孩子D；右子树前序CE、中序EC得到C的左孩子E。因此结构为A左B右C，B左D，C左E。递归时两种遍历对子树的长度必须一致，不能只靠视觉拼图。

### 自测

单独前序或前序+后序一般不能唯一重建普通二叉树；前序+中序在标签互异且输入合法时可唯一。若有重复标签，要提供额外标识或接受多解。只含一个字符的哈夫曼码，理论树深度0，实际编码格式可能约定至少1位，必须以题设为准。
