# 计算机基础概念速查（共识资料）

## 位、字节、字

- **bit（位）**：一个二进制位，只有 0 和 1。
- **Byte（字节）**：8 位。它是内存寻址的最小单位，所以「1 KB = 1024 B」里的 B 指字节。
- **word（字）**：CPU 一次处理的数据宽度，由架构决定（32 位机字长 32 位，64 位机 64 位）。
  注意「字长」是硬件概念，与编程语言里的 `int` 宽度不是一回事。

存储单位换算：`1 KB = 1024 B`、`1 MB = 1024 KB`、`1 GB = 1024 MB`。
但硬盘厂商常按 1000 进制标称，所以买来的 1 TB 硬盘在系统里显示约 931 GB。

## 进制转换

- 二进制 ↔ 十六进制：每 4 位二进制对应 1 位十六进制，`1010 1100` = `AC`。
- 二进制 ↔ 十进制：按权展开，`1011` = 8 + 0 + 2 + 1 = 11。
- 十进制 → 二进制：除 2 取余，倒序排列。

## 抽象与分层

四门课反复出现的同一个思想：

- 组成原理：**存储层次**——寄存器快而小，磁盘慢而大，用"缓存 + 局部性"弥合差距。
- 操作系统：**虚拟机抽象**——进程抽象了 CPU，虚拟内存抽象了物理内存，文件抽象了磁盘块。
- 计算机网络：**协议分层**——每层只关心自己的职责，通过接口与上下层交互。
- 数据结构：**抽象数据类型**——只约定操作与语义，不约束实现（同一个栈可以用数组或链表）。

遇到"为什么要分这么多层"这类问题，答案通常都是：**分离关注点，让每层可以被独立替换与优化**。
